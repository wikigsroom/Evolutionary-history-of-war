# Godot 全面重构结构

## 运行时边界

`GameModel` 是可被无头测试直接驱动的战斗状态机，负责时代、基地耐久、资源、单位生产队列、道具冷却、敌方独立 AI 计时器和事件队列。`BattleScreen` 只负责输入映射、HUD 更新与弹窗；`BattleWorld` 只读取模型并绘制基地、单位与事件粒子。

这条边界专门防止“我方升级后敌方也跟着升级”的共享状态错误。双方时代分别存储于 `sides[0].eraId`、`sides[1].eraId`；`ally_era` 和 `enemy_era` 是各自的只读访问器。进化动作和敌方 AI 分别更新本方状态。

## 菜单层级

```text
营地
├─ 快速战线 → 战斗 HUD
├─ 战役地图 → 时代章节卡片 → 关卡
├─ 军团配置 → 五张兵种卡 + 主动道具槽
├─ 时代百科 → I-V 时代克制与单位
└─ 设置

战斗 HUD
├─ 顶部：我方基地 / 波次 / 敌方基地
├─ 左侧：战线、炮塔、升级、道具入口
├─ 中央：基地、单位、攻击/命中/死亡/进化粒子
└─ 底部：攻击排队、时代升级、基地强化、主动道具
```

## 像素卡片视觉约束

- 4px 间距基线，12-18px 圆角，外框使用 2-3px 像素描边。
- 深海军蓝底承载战场；青蓝只表示我方与可执行操作；红色只表示敌方和危险；琥珀只表示资源/进化。
- 文本只保留标题、状态和费用；兵种职责用图标先于文字。
- `resource-rounded.woff2` 作为游戏内默认字体，字体加载失败时自动回退 Godot 内置字体。

## 演出层

`BattleWorld` 使用合格图集、左右镜头和被裁剪的战场层。`UnitView` 根据模型的行走距离、攻击阶段、朝向与脚底锚点显示角色；AnimationPlayer 管理闪白与基地时间线。`BattleEffects` 消费同一模型事件，复用原生粒子并绘制武器、命中、区域、奖励和镜头反馈；HUD 位于更高层级。

单位让位与冲锋属于模型动作，不能复制给新部署实体；技能炮台使用独立出生状态。相机状态随对局保存，但不参与战斗规则。当前完整检查见 [0.6.1 报告](../../docs/epoch-rush/godot-v0.6.1-repair-report.md)。
