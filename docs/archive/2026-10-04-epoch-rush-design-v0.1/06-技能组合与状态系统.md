# 技能组合与状态系统

## 槽位与执行契约

一个角色专属主动槽 + 两个可选通用槽，共用指挥能量，各自冷却。技能在战前装配，对局中不能临时无限换招。所有通用技能可用时晶辅助器在低时代发动，兵器与表现随后代变化；低时代个人时晶脉冲不意味着全军可提前购买未来兵。

常规施法距离560逻辑单位，以活着的英雄为中心；遗物可增40。己方技能选友方区域，伤害技能选敌方区域。S04/S10/HS02锁定一个敌方实体，其他范围伤害可以对合法空地预判施放并正常扣费。按按钮进入预览，确认才提交；锁定目标消失、越界或英雄倒下使尚未确认动作无效，不扣资源。已成功施放的箭和炮弹在英雄死亡后继续运动。

## 十种状态与控制

| ID | 状态 | 叠加与结束规则 |
| --- | --- | --- |
| ST01 | 破甲 | 减少当前护甲25%，只取较强，不连乘；刷新持续 |
| ST02 | 压制 | 攻速降低20%，炮车命中后施加；同类只取较强 |
| ST03 | 迟缓 | 常规减速30%，专精可45%；只取较强 |
| ST04 | 标记 | 4秒/4次命中，重新施加替换计数，不累加至8次 |
| ST05 | 导电 | 6秒，下一次有效能量命中产生一次40%支链并消费 |
| ST06 | 燃烧 | 基础12/秒，4秒；同类取较强并刷新，不叠十层 |
| ST07 | 护盾 | 可以增加吸收值，但总量不高于最大生命30%；独立到期批次 |
| ST08 | 鼓舞 | 攻速 +15%，5秒；同类光环/鼓舞同槽只取较强 |
| ST09 | 硬直 | 常规0.1秒打断预备动作；随后2秒免疫再次硬直 |
| ST10 | 烟幕 | 投射伤害降低20%；与同类取最强，进入受伤减免池 |

燃烧在整数模拟tick上结算，末次在到期前执行；刷新不会立即补一次额外伤害。死亡实体不保留可触发状态；所有状态的sourceEntityId/sourceSide记录归属。

导电支链不能再触发导电支链；一次伤害施法含主链与支链最多六个不同目标，不能对同一实体反复绕圈。友方护盾/鼓舞可按各自技能作用至多八个目标，不属于伤害链上限。主链目标排序为离上一目标最近，再按entityId；无后续合法目标时结束，不凭空生成伤害。导电在网的初次伤害之后施加，不能由同一个初始命中消费。

裂隙场持续六秒，每秒伤害并刷新一秒减速；离开场后仅保留该次刷新剩余时间，不永久继承场地减速。

击退/聚拢是受控的一维位置调整。轻兵100%、重型20%、英雄50%、基地0%；不会移动到对方基地后方、越过边界或改变队列索敌方向。硬直免疫与位移抗性分别计算，不把任意控制都当成永久眩晕。

## 六条配合逻辑

1. **盾墙/烟幕 → 箭幕。** 保护远程完成出手，产生更多实际命中；保护技能本身不凭空附赠箭幕伤害。
2. **破甲弹 → 集束轰击。** 首发先建立状态，后发命中已破甲目标获得+20%条件加成；额外收益进入统一条件池，不做二次爆炸递归。
3. **共振网 → 脉冲链。** 网限制移动并留下导电，主链消费状态，最多六目标；重型少量部队不一定比单体破甲组合更好打。
4. **引火罐 → 回旋气浪。** 在火区中心聚拢敌人，让范围与持续伤害有效覆盖；重型抗位移，不能把整支重骑军吸成一点。
5. **测距标记 → 连星齐射。** 岚翎三发消费三次标记，剩余一次可留给其他射手；标记不提高燃烧、全屏伤害或所有后续箭。
6. **补给/急行军 → 新时代出营。** 在训练过程中推进剩余时间，让新兵赶上换代窗口；不能缩短还没开始的整条队列至零。

## 组合限制

每个训练项目每种推进来源最多一次，瞬时推进累计不超过原训练时长50%。特殊炮台最多一座，同类光环不叠。伤害、护盾、攻速、收入、费用和冷却均按成长文档上限处理。遗物的技能费用代价在施法检查前计算并显示真实费用。

主动技能打基地按35%基础技能系数结算；不允许控制、导电、标记或燃烧对基地触发二级链式效果。最后一击由普通军团与英雄推进完成，不能在安全基地连续全图施法结束对局。
