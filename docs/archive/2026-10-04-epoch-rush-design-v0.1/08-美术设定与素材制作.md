# 美术设定与素材制作

## 风格基线

温暖、厚重且略带幽默的手绘历史漫画。约2.5–3头身普通兵、3.5头身英雄、约普通兵1.6–2.2倍高的重型单位。粗棕轮廓、两到三层平涂阴影、局部干刷质感。角色与武器先看剪影再看细节；照片质感、等距视角、复杂写实金属和过量霓虹不作为本项目风格。

| 用途 | 色值 | 应用 |
| --- | --- | --- |
| 轮廓 | #3B3028 | 角色与关键武器，实际尺寸线宽2–3px |
| 羊皮纸 | #EDE0C4 | 天空、菜单底色、纸面 |
| 赭土 | #A76D45 | 地面、墙体与历史暖色 |
| 褪青 | #6E9998 | 远山与低对比背景 |
| 盟军蓝 | #397EA5 | 双尾旗、盾面和袖章 |
| 敌军赤 | #B65338 | 三角旗、棱形盾和火力标识 |
| 奖励金 | #E9B751 | 金币、进化可用和少量技能高光 |

战场地面约占画面下部28%，单位集中在一条清楚基线上。背景对比低于角色，前景装饰不能盖住足部和弹道。原提案图只作构图与色板参照，正式战场由可交互单位、基地和分层背景组成。

## 时代的材料语言

石器：兽皮、骨头、粗石；青铜：大块青铜面、城砖、皮带；王国：盾徽、锁甲、旗帜；工业：铆钉、短履带、枪烟和炮后坐；轨道：圆角合金、清楚的电容块、小面积时晶光。每次进化保留同一地面与基地位置，变化建筑层、远景轮廓和武器，不改变摄像机到另一张海报。

英雄六人保持固定身份轮廓与主服装，通过少量时代附件、武器发光与旗帜颜色表达进化；不要求每人每时代重新做一套全身和全动画。六个头像仍须各自有表情和形态差异。

基地武器槽统称炮塔，具体机关随时代变化。动作中的蓄力、发射与恢复也应表现出对应结构，详细对象提示词按TR编号编写。

| 石器 | 木骨投石架，皮索绷紧后弹射 | 木杆抛石器，摆臂与石块抛出 |

## 角色外观规范

砺川：短披风与大双尾旗，宽肩、前倾重心；岚翎：长弓、窄披风、羽形测距器；铎山：方盾、厚肩甲、低重心；绮衡：铜镜、工具背包、机械手套；溯青：环形时晶、长衣、竖直安静轮廓；麦穗：地图筒、行军袋、轻弩。六人至少在灰度剪影下可区别，性格由姿态和动作表达。

## 指定图像路线

使用 `C:/Users/carzy/.codex/skills/sub2-image-gen/scripts/sub2_image_gen.py`，请求模型 `gpt-image-2.5`、high、PNG。生产输出放在 `output/imagegen/epoch-rush/`，入游戏后按清单映射至 `public/assets/`。网关调用不启动本地Docker/WSL/浏览器；凭据留在已有技能配置，不进入文档、提示词或归档。

素材工序：风格母版 → 单位/角色完整图 → 检查角色比例与轮廓 → 去背景与真实alpha检查 → 裁切与脚底对齐 → 可动部件拆分/必要帧序列 → 图集打包 → 实际尺寸播放 → 入清单ready。未经过处理的概念图不能直接标为生产ready。

当前公开脚本为图像生成接口，不能预设参考图编辑和角色一致性功能存在。优先固定文字母版与单角色构图，用部件动画减少重复独立出图；需要帧序列时一次生成整条并做比例/锚点检验，失败则修正或用部件方案，不保证模型会自动返回整齐sprite sheet。调用失败保留原模型，记录错误后重试，不切换供应商。

## 动画清单

每个战斗角色：待机、行走、预备、出手、受击、死亡。英雄另有专属技能动作与重建；重型另有轮/履带、炮后坐或充能。rig用头、躯干、上/下肢、武器、盾/附件的有限层实现，武器与脚部有独立pivot；画面不得呈现所有单位统一整体左右摇摆。

以一次普攻的明确接触帧作为动效核心；走路保持脚底不滑、同类单位共享动画规则但保留动作幅度差异。美术QA必须看实际游戏高度，不能只看512px大图。帧图集建议单页不超过2048，低画质减少帧数与粒子，不改变伤害tick。

## 接入检查

检查文件尺寸、alpha、透明边缘、颜色空间sRGB、朝向、脚底锚点、武器碰撞视觉、阵营灰度差异、攻击帧与伤害一致；输出PNG母版与图集数据。六英雄、五时代和十炮塔必须各有清单状态与负责人记录；当前均由助手负责执行。

生产提示词见[prompts目录](prompts/README.md)，每条标明ID、主体、姿态、镜头、色板、材质与限制。
