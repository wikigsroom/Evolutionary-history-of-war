# 动画制作与QA

首选单角色母版→部件分离→局部遮挡补全→rig。头、躯干、脚、手、武器、盾/附件有稳定pivot和层级；完整角色身份不随帧重画。缺失遮挡区域由局部绘制或单独部件生成修复，必须与母版比例和色板一致。

需要帧图时可使用一次整条生成提示：

```text
One whole animation strip of the exact described original Epoch Rush character, 6 equal slots in one row, all frames facing RIGHT, same silhouette, outfit, palette, shared foot baseline and scale, true transparent background, no scenery, no text. Action: windup, release, impact follow-through, recovery to idle. No camera change, no size drift, no extra characters. Crisp production sprite frames.
```

当前指定生成接口不保证参考图编辑、整齐slot或真实透明；返回图要经裁切、共享缩放、统一脚底锚点和逐帧实际尺寸播放。无法稳定匹配母版的条带不入生产，改用部件动作或重做。

六状态：idle、move、windup、release、hit、dead；英雄附skill、respawn。炮车有轮/履带和炮管后坐，电弧有充能和释放，战鼓有抬槌与鼓皮回弹。对同一动作先定逻辑预备/命中tick，再绑定动画与声音。

QA：脚底不滑、武器握点不漂、头身不变化、攻击朝向一致、镜像阵营标识可读、受击与伤害同步、死亡0.8秒内退出遮挡、六英雄剪影区分、32px图标可读。检查256/384/512母版与实际高度两种尺寸。

图集、部件、预览GIF/视频和rig生成结果作为素材项的派生文件另记，保持母版可追溯。sprite/rig从planned→generated→processed→integrated→verified，只有verified能作为游戏观感完成证据。
