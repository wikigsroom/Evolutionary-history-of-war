# 数值演算与构筑样例

这些演算检查初始表的内部一致性；不表示已在引擎中验证平衡或爽感。

## 开局配兵与预算

A1选择U11骨盾45、U12投石60、U13长矛70，共175军资，初始180余5。串行训练1.6+2.0+2.3=5.9秒；期间无击杀、无其他消费，基础收入47.2军资，余额52.2，学识8.85。可继续补前排，也可存钱买炮塔；开局不是自动满阵。

A4炮车U44的时代价格 `ceil(155×1.45)=225`。工匠尺I03和远征整备T34合计训练缩短11%，原4.2秒变3.738秒，30Hz向上取整113tick≈3.767秒。若还有减训效果超过25%，只按25%上限，不继续叠到瞬间出兵。

## 破甲→轰击

A4集束轰击S05打重骑士U34，基础72、时代倍率2.90、目标护甲22，暂不考虑额外天赋、护盾与减免：

```text
未破甲：floor(72×2.90×0.85×100/(100+22)) = 145
破甲后：floor(72×2.90×0.85×100/(100+22×0.75)×1.20) = 182
```

增加37伤害来自真实护甲变化与已破甲条件加成。S04自己的首发伤害在破甲施加前算，不能把状态给自己的首次伤害重复加成。火炮打重型仍有0.85克制系数，需要实际选择目标；对轻兵则爆炸系数1.25。

## 换代首击与旧兵应对

A4装甲步兵U41基础攻击16，已选两次尖锋合计+10%，命中王国铁盾U31（护甲21、轻型）。无其他减免时：

```text
普通攻击：floor(16×2.90×1.10×100/(100+21)) = 42
战旗首击+20%、突破T15+10%：floor(16×2.90×1.10×1.30×100/121) = 54
```

每名新兵仅第一次成功普攻强化。对方U31时代生命 `floor(175×2.05)=358`，三名新兵也不会靠一次首击自动清掉整个阵列。旗帜加速与前排配合才构成推进。

## 技能能量取舍

B01的P013专属由45增至50，加S04的25与S05的35，总110。常规能量上限100，不能在同一瞬间把三招全放；至少需要恢复10能量，约3.333秒，或选择另一施法顺序。

B05装备蓄压铜瓶I07与断序晶I09，能量上限110；S06/S07费用变35/40，HS05为60，三招总135。满能量先网+链消耗75，余35，要再开裂隙场仍需25，约8.333秒。表中的组合因此不是“无限清屏按钮”。

初始能量仅50，满能量样例是已等待恢复的中盘条件，不把开局误记为110。

## 训练推进

当前炮车剩余训练2秒。S12急行减少15%余时：1.70秒；麦穗整备P063再减少40%余时：1.02秒。这两次缩短0.98秒，低于原4.2秒训练时长50%的瞬时推进上限。每个项目每个来源一次，CD较长，也不能对尚未训练的后续四兵直接生效。

## 护盾上限

HP=400的目标，S01给80护盾；随后HS03试图给100，但总上限120，只能再增加40。两批有效期分别记录，第一批到期只移除仍剩余的第一批值，不把整个120全删。实际先受100伤害时按最早到期批次消耗：80+20，剩第二批20。

折叠盾纹I11改变比例与持续，先计算每次申请，再做总上限；护盾超过上限部分丢弃，不变成隐形延迟护盾。

## 掉落与保底

普通独立箱的某一普通遗物概率60%×25%=15%，某一史诗为10%×25%=2.5%。连续4普通后下一箱只在稀有30/史诗10的权重中重新归一，即75%/25%；已连续19箱无史诗则直接史诗，优先覆盖稀有保底。

重复一件变1碎片，四次重复可定向制作未拥有的一件。前12关首通每关给指定遗物，因此完整收集有确定路径，不依赖随机箱恰好给到想要的构筑。

## 世代节奏模型

四次进化总学识花费160+260+400+600=1420。10分钟基础学识收入900，不计成长；还需约520击杀学识，按普通敌兵8–14平均约52个10学识单位。这只是估计：实际击杀、局内匠学、传承研习、AI进化与关卡上限影响时间。

试玩须记录每次进化时刻、消费结构、英雄倒下时长和战线最远位置。若所有构筑都达不到8–12分钟，先调学识、阶段费用与僵持条件；不能把设计估算当作已证实的时长。
