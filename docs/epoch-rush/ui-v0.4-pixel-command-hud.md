# Epoch Rush v0.4：像素指挥甲板 UI 规范

## 目标

对战界面采用手游战斗 HUD 的信息层级：战场保持可读，顶部只承载双方基地、资源和战斗时钟，底部只承载出兵、主动道具、时代控制和指挥官。所有交互控件保持 44px 以上触控尺寸，文字只承担必要的状态说明，图标负责快速识别。

## 视觉语言

- 外轮廓：深海军蓝底、2px 青灰描边、圆角 14–20px。
- 内轮廓：1px 低透明度浅色描边，加底部 3–5px 深色压边，形成像素设备的实体感。
- 颜色：`#071722`（战场夜色）、`#102c3a`（面板）、`#72d2d1`（己方/交互）、`#edc36b`（资源/时代）、`#ea8574`（敌方/警告）、`#f6e9c5`（主文字）。
- 字体：中文和长文本继续使用项目内置 `EpochRounded`，计时、资源数字和快捷键使用等宽数字；避免不支持中文的 Press Start 2P 作为主字体。
- 动效：只使用轻量的悬停抬升、按下回弹和就绪呼吸，遵守 `prefers-reduced-motion`。

## 图标系统

图标母版由 Sub2API 的 `gpt-image-2.5` 生成，源文件：

`output/imagegen/ui/epoch-rush-pixel-hud-atlas.png`

运行时副本：

`public/assets/ui/epoch-rush-pixel-hud-atlas.png`

母版为 4×4 透明像素图标图集，顺序是：旗帜、剑、盾、书、遗物、齿轮、箭头、暂停、播放、金币、闪电经验、王冠、炮塔、升级、目标、地图。`src/ui/icons.ts` 将高频图标映射到图集，以 `image-rendering: pixelated` 保持 24px 下的硬边；特殊语义图标使用同样方角规则的 SVG 兜底。

## 交互结构

### 对战顶部

1. 左侧己方基地：时代图标、基地生命、点击后定位基地。
2. 中央资源带：金币、XP、军令，数字优先，标签缩小。
3. 战斗时钟：时间和波次状态。
4. 右侧敌方基地：镜像己方基地，用红色生命条区分。
5. 暂停：独立 48px 控件，不与资源混排。

### 对战底部

- 招募区：五张新时代兵卡，编号、像素单位图、金币/锁定状态；下方为人口与训练队列。
- 主动道具区：三枚固定图标槽，右上角显示 charges，底部显示短标签和冷却遮罩。
- 时代控制区：强化、炮塔、时代大招、进化；进化按钮使用更大的琥珀色阶梯强调。
- 指挥官：头像、军令数和生命条；军令展开后显示姿态和技能卡。

### 营地与弹窗

营地、收藏、图鉴、军议和暂停/炮塔/训练队列弹窗共用同一套深色实体面板，采用像素描边和实体底边，避免玻璃模糊、网页表单式白色卡片和大面积文字面板。

## 响应式规则

- 1280×720：顶部 72px、底部约 142px，战场中部完全可见。
- 844×390：顶部压缩为资源段，底部变为两行指挥托盘；隐藏非关键指挥官展开区。
- 760px 以下：招募、道具、时代控件继续保留图标优先布局；控件保持触控安全区。
- 所有浏览器端测试需要确认 `document.documentElement.scrollWidth === innerWidth`，并检查无控制台错误。
