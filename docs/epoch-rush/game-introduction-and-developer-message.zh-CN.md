# 《纪元急袭》游戏简介与开发者的话

## 游戏简介

**十个时代，一条战线。让军团从石器部落一路迈向轨道文明，在攻守与进化之间，找到属于你的制胜时机。**

《纪元急袭》是一款融合横向基地攻防、时代进化与主将构筑的单机策略游戏。你将与敌军分据战场两端，从有限的军资和最初的部队开始，招募士兵、研究军备、部署炮塔、指挥主将，逐步将战线推向敌方营寨。部队会自动行军、接敌和攻击，你负责决定谁先出战、资源如何分配，以及何时发起改变局势的一击。最终目标很明确：守住自己的基地，击破对面的防线。

游戏把十个时代放在同一片架空战场上。石器部落、青铜城邦、古典帝国、中世纪王国、火药列阵、工业战壕、二战钢盔、现代机械化、无人战术与轨道文明，构成一条不断升级的战争路线。骨盾与投石、长枪与重骑、火炮与坦克、无人载具与能量机甲，会陆续改变军团的面貌；基地建筑、主将装备、攻击方式和战场氛围也会随时代推进发生变化。

时代进化是对局中最关键的选择之一。双方分别积累资源、分别决定换代时机，谁率先跨入新时代，谁就有机会凭借更强的军备发起压制。但升级也需要判断：眼前的防线能否撑住，训练中的部队何时抵达，留下来的经验是否足够救场？进化后，新兵目录会更新，已经登场的老兵和先前下达的训练订单仍会保留。新旧军团将在同一条战线上交错，新时代的优势需要通过招募和推进真正送达前线。

当前版本提供 50 个兵种，每个时代包含前排、远程、破甲、重型和支援五类定位。你可以用盾兵承受冲击，让射手在后方持续输出；也可以投入重装骑士、攻城器械或坦克，寻找突破口，再用医疗和辅助单位维持推进。不同部队拥有不同的体积和攻击距离：前排需要取得接敌位置，后方近战单位会等待空间，远程部队则利用射程参与交火。训练顺序、阵线长度和基地出口的空间，都会影响一支军团能否发挥实力。

六位主将为军团带来不同的指挥方式。擅长冲锋的砺川适合前线突击，掌握掩护与护盾的铎山能够稳住阵地，精于工程部署的绮衡可以增设炮台，其他主将则分别侧重远程火力、能量控制与生产补给。每位主将拥有十套时代形态，随着文明进化更换造型、装备与专属技能表现。出征前，你可以搭配专精、通用技能、遗物和天赋；交战中，则能通过撤退、护阵和突击指令，决定主将何时守住队伍、何时投入前线。

主动道具与时代奇袭，让战场节奏掌握在你的指挥中。战鼓令能在短时间内强化军团攻势并推进训练；烟幕罐可以在选定区域拖慢敌军，为重整阵线争取时间；时序补给补充军资和军令，帮助关键订单更快完成。从流星陨火、王国箭雨到制导空袭、轨道审判，不同时代还提供各自的范围打击手段。奇袭与进化共用交战经验，出手解围与保存资源换代，都有各自的收益和代价。

招募之外，你还可以通过军备研究强化部队，建设速射或范围攻击炮塔，调整基地的防守能力。把金币投入眼前的增援，还是积累资源解锁重型部队；借主将技能打开缺口，还是留在阵地等待敌军消耗——每一次投入都会改变后续的节奏。推进、守城与换代可以交替成为你的主线，一场对局也可能在进入最终时代之前分出胜负。

当前版本包含 20 关战役、30 张时代战场全景和三档对战难度。战役围绕军团推进与首领阵线突破展开，带来不同的起始时代、进化上限和敌方增援配置；通关会逐步解锁主将与成长奖励。你也可以从图鉴中选择时代开始对战，熟悉对应的军团与武器。游戏支持本地保存与继续对局，让一次尚未结束的战争，可以在下一次打开游戏时继续。

在表现上，《纪元急袭》以像素角色、鲜明的阵营配色和统一的图标界面呈现战场。刀枪命中、炮口闪光、弹体飞行、护盾破裂、受击与倒下，都配合相应的动作、粒子和声音反馈；从冷兵器的碰撞到机械化火力与轨道打击，军备变化也伴随着不同的声音和演出。你可以通过 Windows 键鼠或 Android 横屏触控进行指挥，在本地单机对战中，体验组建军团、守住阵线，再借一次进化发动反攻的过程。

## 开发者的话

做《纪元急袭》，我们最想保留下来的，是那种从几名原始士兵起步，一边守住营寨，一边把整个军团带向新时代的期待感。最初只有盾牌、石块和长矛，后来是重骑、火炮、坦克，再后来，能量武器与机甲走上同一条战线。每次进化都应该让人期待：军团会怎样变化，下一次进攻又能打开怎样的局面？

项目受到《Age of War》前两部的启发。横向战场、相对而立的基地、不断向前的兵线，以及攻守与进化之间的取舍，是我们希望延续的基础。在这个基础上，《纪元急袭》加入主将、主动道具、军备研究和成长构筑，希望玩家在熟悉的节奏里，拥有更多可以主动决定的事。

对我们来说，时代进化最有吸引力的地方，在于它能够改变一场战争的走向。因此，双方必须独立积累和独立换代；新时代的单位、武器和基地，要让玩家明确感受到军备跨越带来的力量。与此同时，旧兵会继续作战，已经付费的训练订单也会继续完成。进化按钮按下之后，怎样把新军送到前线，怎样处理旧阵线留下的空间，仍然需要玩家指挥。我们希望“升级了”之后，还有一段值得认真打好的反攻。

我们同样重视兵线里每一个单位的位置。盾兵挡住一次冲锋，后排射手得到一段输出时间，重型单位终于接上前线，支援兵把濒危的阵线维持下来——这些具体的变化，是搭配军团的乐趣所在。占位、射程、攻击时序和训练顺序，让玩家的选择落实到战场上；当一次招募或站位调整奏效时，希望你能看清它带来了什么。

主将和主动道具，则是让指挥更有个人风格的一步。有人愿意让主将率先突击，有人更喜欢用护盾和炮台稳住防线；战鼓可以配合一次集中推进，烟幕可以争取重新组织的时间，补给可以让缺少的关键部队更早抵达。我们希望这些能力各有用途，也保留使用时机上的取舍，让玩家逐渐形成自己习惯的节奏。

美术与声音也应该为这些决定提供清楚的反馈。重骑冲进阵线时，动作和命中要体现重量；炮弹落地时，闪光、烟尘与爆炸声要让人感受到冲击；护盾承受攻击、随后破裂时，变化应该足够直观。像素风格让我们可以用鲜明的轮廓和色彩表现不同军备，图标界面则让常用指令更集中，尽量把注意力留给战场。封面上那位身披红金铠甲的骑士，来自主将铎山·铁壁守卫。我们希望这张坚定的面孔，能够成为玩家认识《纪元急袭》的一个标志。

当前游戏以单机对战和战役为核心。接下来的打磨重点，会继续放在不同兵种的用途、跨时代攻守的节奏、主将与道具的配合，以及操作和战斗反馈上。内容增加之后，每一种选择是否仍然有意义，每一段战斗是否仍然容易看懂，都需要通过实际游玩反复调整。我们希望保留进化带来的明显优势，也让防守、资源分配和临场指挥始终值得投入。

如果你愿意尝试这款游戏，我们很希望听到具体的体验：哪一种兵总能派上用场，哪一个时代容易陷入僵持，哪次技能改变了局势，又有哪些时候，你明白自己想做什么，却觉得操作或画面没有及时回应。这些战场里的细节，会帮助我们判断下一步应该优先打磨哪里。

感谢你把时间交给《纪元急袭》。希望在某一场基地濒危的对局里，你能守住最后一段防线，完成期待已久的换代，然后看着新军接上前线，把战场一点点推回去。那会是这款游戏最想与你分享的时刻。

——《纪元急袭》开发者
