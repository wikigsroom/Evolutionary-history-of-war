# v0.3.1 战斗扩展与 UI 重构

> 日期：2026-10-06（Asia/Taipei）  
> 基于 v0.3.0 最终交付基线，继续遵循用户指定的 Sub2API `gpt-image-2.5` 素材路线。

## 目标

本补丁直接回应四项战斗问题和一项界面问题：基地与人物的比例不够有冲击力；时代兵种缺少能改变阵线节奏的特色角色；主动道具不足；命中、受击、死亡和施法缺少层次；HUD 仍有过多文字和大块面板。

## 玩法扩展

### 更大的基地锚点

两侧基地的战场展示高度从 236 提升到 340，增加了城墙、旗帜、门洞、底座和环形护盾的层次，基地生命条仍由原有逻辑半径控制，因此不会改变碰撞、胜负或人口占位规则。基地被命中时使用更大的火花、烟柱和护盾脉冲，残骸状态保留在原有战斗事件协议内。

### 五个时代特种单位

特种单位使用稳定的 `U15/U25/U35/U45/U55` ID，拥有自己的数据、头像和独立 30 帧动作图集；加入后完整动作门禁由 26/26 扩展为 31/31。首屏仍只加载 A1 初始单位和首位英雄，其余图集按实体出现动态加载。

| 时代 | 单位 | 阵线定位 | 特色能力 |
| --- | --- | --- | --- |
| A1 石器 | 祭火鼓手 | 前排支援 | 半径 150 内友军攻击速度 +12%，用鼓点改变早期推线节奏 |
| A2 青铜 | 太阳旗卫 | 前排支援 | 半径 160 内友军攻击速度 +14%，让盾墙和远程齐步压线 |
| A3 王国 | 猎隼斥候 | 破甲接敌 | 完成最小行进距离后首次接触获得 +35% 冲击伤害 |
| A4 钢铁 | 战地医师 | 后排支援 | 半径 165 内友军持续恢复生命，受击后能把阵线拉回可战状态 |
| A5 轨道 | 时序工程师 | 能量支援 | 半径 180 内友军周期性获得微量护盾，抵消一次关键火力窗口 |

光环同类取最强值；治疗和护盾按战斗 tick 限频；单位仍受人口、出生时代和出口堵塞规则约束。头像路径为 `public/assets/ui/units/U15.png` 至 `U55.png`，源图、提示词和元数据位于 `output/imagegen/epoch-rush/v0.4-specials/`。

### 三个主动道具

主动道具和技能使用同一套指向、取消、冷却、存档和输入协议。自指向道具点击后立即生效，区域道具进入“点选落点”状态，右键或 `Esc` 取消。

| 道具 | 快捷键 | 初始次数 | 冷却 | 效果 |
| --- | --- | ---: | ---: | --- |
| 战鼓令 | G | 2 | 22 秒 | 全军短时攻击与移动增益，并推进一段出兵队列 |
| 烟幕罐 | V | 2 | 28 秒 | 以战场点为中心减速敌方非基地单位，半径 135 |
| 时序补给 | N | 3 | 30 秒 | 补充金币与军令，并推进一段出兵队列 |

道具数量、冷却和目标点写入 `SideState`，旧存档由 `validateSnapshot` 自动补默认值；异常数量、未知 ID、越界目标和冷却中的重复施放都会被拒绝。

## 打击与反馈

战斗表现分为“预备—释放—命中—受击—死亡”五段：

- 释放时从武器挂点喷出短促的火花/能量粒子，远程弹道保留原有命中时序。
- 命中时叠加扩张冲击环、颜色编码的粒子爆发和伤害浮字；护盾、治疗、减速与道具使用各自有不同色相。
- 受击时由实体的 `hit` 状态、轻微位移和事件粒子共同反馈，基地额外触发护盾椭圆脉冲。
- 死亡时保留原有淡出/倒地流程，并提高烟尘和残骸反馈的可见度。
- 道具施放使用全战场环形脉冲；战鼓和补给额外显示短浮字，烟幕保留区域云团而不遮住主要阵线。

粒子采用轻量 Graphics 对象和短 tween，统一受 `prefers-reduced-motion`/游戏内降低动态设置控制；瞬时效果上限从 100 提升到 180，避免密集交战时出现“没有打击感”的稀疏画面，同时仍限制对象数量避免无界增长。

## UI 体系

### 结构

战场采用三层结构：

1. 顶部是双方基地生命、金币、XP、军令、计时和暂停按钮；资源使用图标胶囊，文字只保留数值和无障碍标签。
2. 中央是净战场区，基地和人物获得完整纵向空间，镜头跟随不被面板遮挡。
3. 底部是玻璃指挥甲板：五张兵卡、在场人口、三个主动道具和进化/炮塔/时代大招按钮。卡片使用圆角、图标、数字和冷却遮罩，特种单位用 `✦` 徽记提示。

所有可点击控件保持至少 48px 触控尺寸；手机横屏时兵卡和道具自动压缩为同一行，短屏时允许横向滚动。按钮均有 `aria-label`/title，图标不足以表达语义时再补充短标签。

### 视觉令牌与字体

本次布局依据 `design-system/epoch-rush/pages/battle-ui.md`、`game-ui-frontend`、`ui-ux-pro-max` 和 `frontend-design` 的战斗页约束：玻璃空间 UI、移动优先、避免不透明大面板、保持中央战场净区、图标优先、减少持续抖动。实现集中在 `src/ui/rounded-theme.css` 的 v0.3.1 覆盖段。

- `EpochRounded`：资源数值、短标签和按钮文字，适合小尺寸阅读。
- `EpochDisplay`：时代名、标题和关键状态，保留手绘文明感。
- 主色沿用暖谷背景、深靛玻璃、青色生命/护盾和金色 XP；敌方受击使用赭红，治疗使用青绿，烟幕使用冷灰蓝。
- 圆角半径集中在 19–28px，卡片阴影和描边采用低透明度，避免遮挡战场。

## 验收口径

必须同时满足以下条件才视为本补丁可交付：

- 五个特种单位能够训练，光环、首触冲击、治疗和护盾在模拟战斗中生效。
- 三个主动道具具有次数、冷却、目标校验、存档迁移和 UI 反馈。
- 基地尺寸、五张兵卡、三枚道具按钮和图标胶囊在桌面与横屏手机布局可见。
- 命中、释放、道具施放和基地状态变化不产生控制台错误，瞬时效果受上限与降低动态设置约束。
- `npm test`、`npm run build`、资产完整性、动画预算、平衡模拟、Windows/Android 包校验均通过。

五个特种单位的动作母图、归一化图集、敌我变体、挂点、身体占位和四组合录像均由用户指定的 Sub2 `gpt-image-2.5` 路线生成并验收；当前动画门禁为 **31/31**。新增图集仍受首屏动态加载预算约束，后续若继续新增角色，应先扩展预算并逐帧审查。
