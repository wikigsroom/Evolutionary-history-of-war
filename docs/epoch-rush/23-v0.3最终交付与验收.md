# v0.3.0 最终交付与验收

日期：2026-10-06（Asia/Taipei）。项目：**一线万年：文明冲锋 · Epoch Rush**。本记录对应当前源码、资源和发布包；旧版候选包及历史记录保留在原路径，不作为本次最终包的依据。

## 交付结论

v0.3.0 已形成可玩的五时代横向战线游戏，玩法核心、动作表现、圆角图标 UI、跨时代成长与跨端工程均已接入。26 名角色（20 兵种、6 英雄）的 Sub2API `gpt-image-2.5` 动作图集已完成 30 帧归一化、敌我变体、攻击/命中挂点、身体占位和原速/四分之一速完整序列验收，最终发布门禁为 **26/26**。

## 美术与素材来源

- 所有本轮新角色动作源图来自用户指定的 Sub2API `gpt-image-2.5`，记录为 `route: Sub2 CLI edit`，保留角色参考图、提示词、元数据、原图 SHA-256 和复核记录。
- `tools/process_animation_sheets.py` 将源图裁成统一 128/160 方格图集，补齐透明边界、锚点、身体半径和 muzzle/hit socket；敌我颜色变体复用同一动作身份。
- 运行时首屏仅加载 A1 四兵种与 H01，其余已接受图集按实体进入战场动态加载。初始解码估算为 24,084,480 bytes，预算 67,108,864 bytes；见 `output/qa/v0.3/animation-loading-budget.json`。Canvas 会公开当前 loaded/loading/estimated/peak 数据供桌面 QA 读取。
- 基地、炮塔、背景、技能、状态和 FX 仍使用随包的原创素材；字体为随包资源圆体与得意黑子集，许可文件和来源一并归档。

## 可玩规则摘要

经典对战从 A1 推进至 A5，金币训练、同代研究、炮塔和战斗 XP形成循环。进化与时代大招共享 XP；玩家在时代窗口决定是立即换代还是保存资源发动时代打击。兵种有前排、长矛、远程、重型和攻城角色，身体占位决定合法接敌与攻击排队。可选英雄扩展加入一名真实战场指挥官、专精、军令、遗物和传承；驻营与归队不会堵住基地出口。战役含 15 关，另有演练与固定构筑挑战。

## 验收项目

最终交付前执行以下命令并将结果写入 `output/qa/v0.3/`：

```powershell
npm test
npm run build
node tools/check_animation_budget.mjs
node tools/release_gate.mjs
python -X utf8 tools/validate_assets.py
```

之后使用 `node tools/pack_desktop.mjs`、`node tools/build_android.mjs`、`python -X utf8 tools/archive_source.py` 生成 Windows、Android 和源码包，再用对应 `verify_*_bundle` 脚本校验。Windows、Android 与 Web 共用同一 `dist/`；iOS 工程已同步，但 Windows 环境不声称已编译或签名 IPA。整个过程只使用本机 Windows 进程，不启动 Docker、WSL 或其他虚拟化环境。

本次实际结果：`npm test` 为 **109/109**（8 个文件）；标准自动策略样本为 6 场，其中经典 3 场胜利、英雄扩展 2 场胜利、1 场在 900 秒上限结束；战役合法操作样本 15/15 胜利；动画门禁 26/26；动画首屏预算 24,084,480 / 67,108,864 bytes；Windows 与 Android 各 657 个 Web 文件校验通过；Electron 菜单启动检查通过。按需加载浏览器检查中，A5 兵种和六名英雄均显示已接受图集，加载完成后没有错误日志。
