# Epoch Rush UI 方向选型结构说明

这 5 张方向板使用完全相同的战斗 HUD 信息架构，只改变视觉风格，避免因布局变化影响判断。

## 固定画面结构

- 画布：横向 16:9 战斗场景，中心保留开阔的文明进化战场和清晰的兵线。
- 左右两侧：体量明显的己方与敌方基地，基地尺寸必须明显大于单个单位；基地上方显示时代徽记、生命条和阵营色。
- 顶部状态带：左基地状态、中央分段资源带（金钱 / XP / 军令）、战斗计时与波次、右基地状态、暂停按钮。
- 左上辅助控件：小地图、跟随前线、训练队列、兵种说明，使用图标优先的按钮。
- 底部指挥托盘：左侧 5 张当前时代招募卡，中间 3 个主动道具槽，右侧强化 / 炮塔 / 时代大招 / 进化按钮，最右为指挥官头像和军令值。
- 文本：只保留短标签和数字，优先使用图标；可出现短中文标签“金币、XP、军令、招募、道具、进化”，禁止大段说明文字。
- 交互暗示：按钮有明确的可点击状态、冷却遮罩、锁定状态、可进化高亮状态；所有按钮至少 44px 触控目标。
- 游戏内容：原创五时代历史科幻战争游戏；石器、青铜、王国、工业、轨道文明的徽记可以出现在卡牌和基地上；不要出现 Age of War 或其他现有游戏标志。

## 统一评审问题

1. 一眼能否分辨战场、状态带和指挥托盘？
2. 不看长文字是否能识别招募、道具和时代进化？
3. 基地与单位是否有足够的体量对比？
4. 视觉风格是否能支撑攻击、受击、升级和时代跨代的爽感？
5. 是否适合后续用 HTML/CSS/Phaser 实现，而不是只能做成静态网页图？
