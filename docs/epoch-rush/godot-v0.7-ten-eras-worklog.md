# 十时代扩展：问题检查、修复方案与交付记录

基线：Godot 0.6.2。交付版本：0.7.0。九项功能、素材和 Windows / Android 构建已完成；实际验证结果与平台边界见 [最终交付报告](godot-v0.7-ten-eras-report.md)。本页保留实施起点与检查发现。

| 用户要求 | 当前检查发现 | 实施方向 | 最终需要的证据 |
| --- | --- | --- | --- |
| 医疗与盾血叠加 | 医疗光环每个 30 Hz tick 加一次完整治疗，多医疗兵叠加；被动盾重复补充 | 改为定时治疗、有限目标；血量与被动盾共享持续战斗恢复预算；血条与盾条独立显示 | 多医疗兵、护盾与护甲组合的持续接敌测试，治疗速率和有效血量检查 |
| 升级过快 | 经验奖励和战斗强度使用同一个倍率，升级门槛仅 85/150/250/390 | 十阶段门槛扩展；经验独立倍率，避免 5 倍伤害同时产生 5 倍经验 | 十代经验表、多种子对局时代停留时间、旧兵与订单检查 |
| 奇袭表现弱 | 以通用线段和圆环为主，没有完整时代发射与落点素材 | Sub2 生成十套载具/弹体/冲击/碎片/烟尘，形成预警、发射、命中、余波演出 | 原始生成记录、实际运行的十代奇袭录像和伤害验证 |
| 跨时代至少五倍伤害 | 现有相邻时代基础倍率约 1.6 | 同定位同研究攻击五倍，生命与基地同步尺度，伤害/经验/价格分开 | 50 兵种与相邻时代伤害/DPS矩阵、巨大数值显示检查 |
| 十时代 | 当前五时代，多处上限与 ID 解析写死 | 石器、青铜、古典、中世纪、火药列阵、工业战壕、二战、现代机械化、无人战术、轨道 | 十时代招募、研究、炮塔、百科、战役与独立进化验证 |
| 动态背景 | 当前固定夜景，无时代天空角色 | 时代匹配的鸟、蝙蝠、气球、飞机、无人机、穿梭机；仅表现层 | 暂停与性能、无碰撞/伤害/奖励的检查和录像 |
| 三候选背景 | 当前单张夜景 | 十时代各三张；每次任一方升级抽取对应最高时代的另一张背景并过渡 | 30 张真实素材、所有候选可达、任一侧升级换图、时代状态不联动 |
| 随机弱奇袭 | 当前无环境事件 | 独立随机流、提前预警、有限伤害、双方可能受影响、不给击杀奖励、不伤基地 | 多事件种类、时间/伤害/暂停/快照/随机流隔离检查 |
| 主将随时代迭代 | 数值随时代，造型和专属技能基本固定 | 六位主将各十套造型与技能变体，共 60 形态；升级保留生命比例与技能冷却 | 60 形态素材、逐代技能行为与数值、在场升级换装、阵亡重生检查 |

地图遵循双方最高时代；每次任意一方升级都会换图。落后方追平但未提高最高时代时，抽取当前主导时代的另一个候选，避免地图跳到双方都未达到的科技水平。地图变换不改变双方单位时代。

本轮按用户新要求实现五倍时代断层，替代上一轮构思中较温和的跨时代平衡方向。代差将很强，因此升级经验和同代作战节奏一起校准。

素材通道固定 `sub2-image-gen` / `gpt-image-2.5`，不改用其他模型。角色按完整动画图集生成，并以共享缩放和落脚点规范化。原始文件和提示词保留于 `output/imagegen/ten-eras/`。

历史识别参考：[线列步兵与燧发枪](https://www.nam.ac.uk/explore/rifle-brigade-prince-consorts-own)、[近现代火力与刺刀](https://www.nam.ac.uk/explore/battle-boyne)、[海湾战争机械化](https://www.nam.ac.uk/explore/gulf-war)。这是架空像素文明战争，不声称每一单位或跨代性能倍率是历史模拟。

最终完成 420 项规则、203 项技能、45 项存档恢复、120 个敌我主将形态、159 项交互与 265 项音频检查；全部 30 张地图实际加载，八场完整对局结束且占位无重叠/普通路径跳跃。最终包、素材哈希和截图见 [交付报告](godot-v0.7-ten-eras-report.md)。Android 包通过签名、16 KB 对齐和内容校验，当前未连接真机。
