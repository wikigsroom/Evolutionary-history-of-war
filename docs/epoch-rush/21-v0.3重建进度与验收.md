实现决策：

- 默认入口为完整五时代文明对战；英雄军令作为可选扩展，所有英雄与技能仍可使用。
- 同时代金币强化与时代进化分开；时代大招与进化共用 XP；旧训练订单/场上旧兵保留出生时代。
- 角色以完整姿态序列为主，使用一张整表建立身份与动作一致性；用户指定的 Sub2 CLI 是唯一生成路线。已核实当前 CLI 提供 `edit --image` 参考图输入，使用现有角色母图保持身份；先审查代表角色后再扩展全部 26 名角色。
- 保留固定 30Hz 模拟与 Phaser 表现分离；移动占位不能依赖渲染帧率或单位编号余数。
- 英雄撤回后进入基地驻营，每秒恢复 2.5% 生命，停止攻击和施放军令；掩护/冲锋指令请求归队，出口占用时继续等待。驻营、恢复余量与重返战场写入存档。这是本作的扩展规则。
- 普通对战采用公开的每分钟出兵/集结节奏，战役采用有限增援；重型普通攻击有攻城加成。均为本作的节奏设计，不冒称原作的已核实规则。
- Windows 本地执行，不启动 Docker/WSL；每次浏览器验证后关闭不用的标签。

历史记录中的未通过项不代表当前最终状态；当前完成项和限制请以 23 号最终记录与最新 QA 文件为准。
