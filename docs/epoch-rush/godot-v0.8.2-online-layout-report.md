# v0.8.2 联机页面与自动连接调整

正式客户端固定连接 SIDcloud 服务，页面不显示服务器地址，也不提供修改入口。升级时忽略旧版本保存的自定义地址并保留构筑；新的会话文件不再保存地址。用于隔离测试的环境配置仅对原生编辑器有效，正式导出程序忽略此配置。

进入页面请求一次连接，重复进入不会重置正在进行的连接或重试计时。首次失败、空大厅断线及身份过期也进入自动重连流程，解决过去只有活动房间或对局才会重连的问题。大厅按 2、4、8 秒退避，后续保持 8 秒间隔；HTTP 请求有 8 秒超时，实际重试开始时间受前一请求耗时影响。对局继续沿用原有 WebSocket 恢复流程。应用后台暂停轮询和重试，前台自动验证身份并恢复原活动。网络操作恢复前禁用匹配、入房及准备，版本不兼容或身份保护失败显示具体原因。

增加大厅轮询请求的代次检查，避免加入、离开或准备操作之前的旧响应覆盖最新房间状态。直接刷新会等待进行中的轮询完成；自动轮询不会重复启动相同请求。结算后不再标记战局断线或安排原局重连。

验证使用最终 Windows 导出资源包，不以编辑器页面代替发布内容。版面 65 项覆盖大厅、匹配等待、单人房间、双人房间、准备、邀请接受、继续对战及结算，五种窗口尺寸与安全区留白，以及六位主将。独立网络故障测试 12 项覆盖 HTML 网关错误、首次失败、空大厅断开、重复重试、后台暂停、前台恢复与身份过期。公共服务器双客户端 24 项验证自动连接、六位码、构筑、双方准备、真实指令、原局重连与重启恢复。旧配置迁移检查 5 项。

双 APK 的脚本及字体与 Windows 导出资源逐字节核对，并检查版本、权限、Keystore 插件、签名与 16 KB 原生页对齐。Android 实体设备操作仍待验收。截图中的真实公共对局和用于检查邀请、排版的状态样例在来源记录中分别注明。[证据目录](../qa/v0.8.2/README.md)。

本次仅更新客户端与说明。在线模拟协议及哈希未变，沿用已部署的 0.8.1 服务；没有停机、数据库迁移或扩大公共服务容量。隐私文件与 https://jyqx.sidcloud.cn 同步调整，保留 SIDcloud 主体与新加坡处理地区。
