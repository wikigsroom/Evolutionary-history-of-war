# Godot 成品打磨与验收契约

本文件对应持续目标：菜单/UI、游戏规则、人物动作与攻击演出全面超过迁移前的版本；严格落实方案 1，交付实际可运行产品。打包成功、场景可启动或少量测试通过均不能代替完整验收。

## 视觉基线

参考 `output/imagegen/ui-selection/01-pixel-card.png`，实现顶部生命/资源/计时条、横向四枚辅助按钮、净战场、大型基地、五张纸色招募卡、三枚道具卡、研究/炮塔/时代技能、金色进化主卡、指挥官圆形头像。像素切角、明暗压边和内部高光必须实际呈现；禁止以通用圆角深色矩形替代。中文使用本地圆体，标题使用得意黑，数字采用稳定的等宽风格。

菜单延续相同的像素卡片材质和夜间战场世界，提供实际生效的快速对战、战役选关、英雄/专精/技能/遗物/天赋配置、百科与设置。任何入口都必须实际改变状态，禁止只弹出“面板已并入”之类提示。

## 规则要求

- 五时代独立推进，旧兵和付费训练订单保留原有时代，新订单使用新目录。
- 30Hz 固定步长；训练 FIFO、取消退款、出口阻挡、人口上限可验证。
- 同地面战线的真实体积占位，近战队首接敌、长兵越肩、远程并行输出、死亡补位、击退修正。
- 经济、战斗 XP、同代研究、重型解锁、炮塔建造/出售/插槽、时代技能与进化 XP 取舍。
- 25 兵种的各时代属性与特殊能力、6 名英雄、主动技能、主动道具、敌方独立决策、难度与胜败结算。
- 15 战役关卡、解锁/奖励、配置与战斗存档、本地设置，退出恢复不能重复奖励。

## 动作与演出要求

按角色元数据加载 sprite sheet、脚底锚点、尺寸、武器挂点和受击挂点。行走跟随距离；蓄力、释放、恢复、命中、硬直、死亡消费同一模拟 tick。近战接触后扣血，弹道抵达后扣血；表现不能凭独立动画循环制造命中。

攻击反馈按武器和目标材质分类；普通命中、重击、护盾破裂、治疗、火炮、电弧、烟幕、英雄技能、进化、基地破损与崩塌具有不同的形状、时长和强度。镜头与音频和事件同步；降低动态保留必要反馈。

## 验收证据

1. 模型回归：时代独立、训练时代、接敌/占位/堵出口、弹道与伤害时序、技能/道具/升级、暂停、存档恢复与奖励去重。
2. 标准完整对局与不同打法：真实招募、进化、强化、技能、胜败、再战，记录可复验输入与结果。
3. 全兵种/英雄动作覆盖检查与代表角色原速/慢放演出录像。
4. 对比设计稿的桌面与移动横屏截图、实际按钮交互与布局尺寸检查。
5. 常态/高压力场景帧耗时、资源峰值与输入验证。
6. 成品包重新导出，Windows 实际窗口启动及全流程复验，Android 包签名/内容校验，真实设备验证与未验证边界如实记录。
