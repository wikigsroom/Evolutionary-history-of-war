# 玩法深化与公平对决构思

日期：2026-10-07。基线：Godot 0.6.2。状态：设计提案，以下新增规则与数值尚未进入运行版本，原型数值需要对局验证。

建议把下一轮玩法更新集中为一个「公平对决」模式：双方竞争金币、战斗经验、军令和战线，围绕出兵组合、进化时机和有限战术资源做选择。保留横向单战线、身体占位、进攻排队、五时代进化的识别度，让出兵顺序、时代优势和技能时机形成可读的来回交锋。

## 1. 现有基础与真正的缺口

以下是对当前运行代码的核对，历史设计目录中的目标数量不等于已实现功能。

| 已有基础 | 当前状态 | 下一步要解决的问题 |
| --- | --- | --- |
| 五个时代与旧兵保留 | 双方时代独立；旧兵和已付费订单保留原时代，招募目录随本方更新 | 升级时机除了经验是否足够，还应取决于军资、阵线与敌方战术资源 |
| 金币、战斗经验、军令 | 出兵/研究/炮塔消耗金币；时代进化和时代大招共用经验；英雄技能消耗军令 | 三种资源已有用途，优先增加用途之间的取舍 |
| 25 种兵与 6 名英雄 | 每代五个招募槽；有前排、远程、破甲、重型及特种能力 | 部分克制依赖伤害倍率，需要增加阵形、行动条件与可执行的反制 |
| 身体占位与接敌 | 有体积、堵出口、前后排接敌；部分长兵器可隔一名友军攻击 | 出兵顺序重要，但玩家对集结和分批出营的控制不足 |
| 技能、时代大招、三种道具 | 有预警、护盾、破甲、减速等；时代大招有 23 tick、约 0.77 秒预警 | 预警必须对应玩家来得及且有能力执行的应对；技能/道具需避免功能重复 |
| 研究与炮塔 | 金币强化、重型解锁、三个炮塔槽、出售退款 | 需要逐步形成可辨认的投入路线，不能每局最终都点满同样项目 |
| AI | 共用资源、招募与伤害规则；按决策间隔行动 | 选兵主要看自己的前后排数量与随机阈值，经验足即进化；尚无完整的对手阵容评估、时代大招决策及三种道具调度 |

对应代码：[战斗模型](../../godot/scripts/game_model.gd)、[接敌与伤害](../../godot/scripts/epoch_combat.gd)、[技能与道具](../../godot/scripts/epoch_skills.gd)、[研究和时代大招](../../godot/scripts/game_data.gd)。

特别需要检查时代雪球：现有时代倍率同时放大生命和攻击，相邻时代倍率约为 1.6。仅在其他条件相同时，这两项相乘就会显著放大战斗优势；具体胜负还受价格、护甲、射程和编队影响，不能仅用单兵伤害判断。新增博弈前，应先测同金币预算、同生产时间下的跨时代混合编队。

## 2. 「对等」的规则契约

对等指双方获得相同的选择机会和执行规则，阵容、战果及时代进度可以不同。主张为该模式建立以下明确契约。

| 维度 | 公平对决规则 |
| --- | --- |
| 起点 | 相同初始金币、经验、军令、基地、人口和训练容量；地图左右镜像 |
| 内容预算 | 全部竞技兵种与战术选项开放；英雄、技能、专精使用相同槽位预算；局外成长采用统一竞技模板，遗物/天赋转为等预算横向选择 |
| 经济与生产 | 相同价格、收入、奖励、冷却、训练时长、出营空间和取消退款；不为 AI 提供免费单位、金币、经验或特殊升级 |
| 进化 | 各自积累和消费经验；本方升级不改变对方时代、资源或订单 |
| 公开信息 | 已出营部队、英雄、炮塔、时代、完成的研究/路线和战场预警公开；公开战场信息不以当前镜头是否覆盖为界 |
| 私有信息 | 未出营订单、集结预备队、精确资源库存和未使用道具余量私有；双方只能根据公开行为估计敌方预算 |
| AI 获取信息 | 仅接收公开观察快照及自己的私有状态，不直接读取玩家训练队列、剩余金币、未发出的指令 |
| AI 难度 | 通过规划、反应间隔和失误率区分；强 AI 也必须等待预警出现，并经过规定的反应延迟 |
| 操作与反制 | 双方都能集结、反制、抢目标和调度技能；高威力机制至少提供一种不依赖特定英雄的基础应对 |

战役已有的不同起始金币、Boss 基地和援军是关卡设定。公平对决使用独立配置与入局校验，避免这些关卡参数被带入同规则比赛。该模式首先适用于对 AI；真人联网还需要独立处理权威判定、连接、同步和断线，不把当前单机原型视作已经具备联网交付能力。

## 3. 优先深化的六组机制

### 3.1 编队克制：让同样的钱产生不同战果

维持每代五张招募卡，先强化现有兵种的职责和行为。

| 部队职责 | 获得的优势 | 必须付出的代价 | 对方如何应对 |
| --- | --- | --- | --- |
| 盾卫 | 举盾阶段抵御来自正面的直射，保护支援队 | 举盾时攻击或前进效率下降；不能抵御所有爆炸与区域持续伤害 | 用慢速抛射、破甲、区域火焰处理，或等盾阵转入进攻 |
| 长矛/破甲兵 | 在第二排支援；站稳后对冲锋重型有额外收益 | 准备时间、有限接敌距离；失去站稳状态时收益下降 | 用远程持续压制、先以廉价前排接敌，让重型等待反冲锋状态结束 |
| 远程 | 在有效前排保护下持续输出 | 身板脆、射程有限；攻击需要合法弹道和目标 | 击破前排、迫其越出防线，或用可预警抛射处理集中的支援队 |
| 重型 | 有足够助跑距离时冲击或拆城强 | 占位宽、昂贵、训练慢；连续堵在友军身后不能获得冲锋收益 | 架矛、减速、阻断助跑，用破甲队换掉高投入目标 |
| 特种支援 | 鼓舞、治疗、护盾或训练联动 | 支援叠加有上限，自身作战效率有限；保护它占用编队空间 | 通过合法抛射、破阵或已暴露目标的集火打击；不能无视阵线直接点杀 |

直射被前方敌军截挡；抛射可以越过盾阵，但落点和飞行时间可见、飞行较慢。这样同一套「伤害类型克制」会进一步成为保护、破阵和出兵顺序的博弈。已有特种单位优先调整角色行为，不必先增加一整代新角色资产。

关键约束：单位不能为了执行克制而无条件穿过友军或敌军。新的举盾、架矛、整队行为都必须遵守占位；标记目标也不能赋予无限射程或瞬移弹道。克制提供优势，但不把不利编队变为必输。

### 3.2 受控集结：争夺出兵时间，而非连续点击同一张卡

增加基地端的「直接出营 / 集结」切换，以及一个「出击」操作。

- 集结时，训练完成的单位进入最多三个位置的营地预备队，继续计入人口与生产预算，保留订单时代。
- 预备队满时，完成的订单等待释放，后续训练不能继续越过它；避免无限囤积再瞬间倾倒。
- 出击按既有顺序释放，每个单位仍需真实出口空间；不瞬移到前线，不凭空获得攻击加成。
- 集结结束后可恢复逐个出营。敌方看到的是出营后的编队，不能预读营地隐藏订单。
- 切换集结不能暂停已经发射的弹道，不能通过待命取消损失而获得免费资源。

新的决策是：单兵立即补线、等盾卫与远程一同出营，还是故意发一小波诱出清场技能。集结的成本是前线暂时缺少增援、人口被占用和生产可能受阻。

### 3.3 进化时机：把时代优势转化为有风险的投资

保留「战斗经验用于进化或时代大招」的现有核心取舍，在公平对决原型中试验额外的进化军费：约一至两名本时代普通兵的价格。它是待测原型，不是已经决定的正式数值。

时代升级仍立即完成；旧兵和已付费订单保持原时代。额外军费让早升级减少眼前可投入的增援，玩家需要判断能否用当前阵线撑到新兵抵达。升级的优势来自新兵、基地和现有换代冲锋窗口，不能自动改变敌方，也不把全部旧兵免费变成新兵。

形成三种可竞争的计划：

| 计划 | 要赢在哪里 | 对手的应对 |
| --- | --- | --- |
| 抢时代 | 用新兵突破，取得后续生产优势 | 在其支付军费、尚未形成新编队时压线；保留反重型与防护 |
| 留代压制 | 把金币投入完整编队和同代研究，利用生产窗口 | 保住阵线，完成科技后用合适组合反推 |
| 经验奇袭 | 花经验清场，利用空档抢目标或拆城 | 分批出营、基础防护减损，利用对方延迟升级建立下一波优势 |

保留现有己方正常战损获得部分经验的规则作为公开机制。落后一代可以靠组合与时机争取机会；不提供自动追平时代、暗中赠币或按落后幅度直接加伤害。跨两代应仍有明显的科技差距。

### 3.4 技能与道具：强招可以被识别、诱骗和应对

时代大招已有预警，下一步验证的是这段预警是否真的能操作。横向自动战斗中，画出圈却没有可执行应对并不构成足够的反制。

- 高伤害大范围招式使用清晰的像素落点与音效预警。原型从约 0.8–1.2 秒的窗口测试，具体取决于范围和影响，而不是给所有技能统一延迟。
- 公平对决提供双方共有的基础防护：短时减伤、不能清空既有持续伤害、消耗军令且有冷却。放在英雄指挥操作中；这是通用应对，不依赖抽中特定英雄。
- 防护与进攻技能争用军令。先交防护会暴露一段弱势时间；全部军令用于爆发，也意味着无法对下一次大招有效减损。
- 已发出的敌方弹道不能被操作反悔；施法取消、打断和是否退还资源必须预先规定，避免免费试探。
- 道具从全员固定携带三种，调整为战前有限槽位选择；首轮先试两个槽位、固定总充能预算。
- 战鼓用于推进；烟幕明确改为削弱直射的区域掩护，抛射和持续区域伤害仍能处理它；补给优先提供训练推进，避免同时白送金币、军令与训练而形成无条件的开局必按按钮。
- 同类加速和防护设叠加上限；道具连续使用设短公共间隔，避免三个效果在一瞬间堆满。

需要区分现有行为：目前名为「烟幕罐」的主动道具实际主要减速敌军，以上掩护效果属于拟重定义内容。技能栏已有烟幕、战鼓和急行军，也需同步梳理互相替代的收益与资源代价。

### 3.5 中立补给：让战线位置拥有额外价值

首个原型只设置一个中央定时补给点。试验节奏为每 60–90 秒出现一次，提前 8 秒显示预告，固定地点公开，避免随机刷新偏向某方。

- 仅一方正常地面军团在捕获范围内、且持续约三秒无敌军争夺时领取；召唤物和驻营单位不能单独领取。
- 双方都有单位时捕获停止；双方都离开时捕获进度重置。
- 单次奖励先测试约 25 军令，并受军令上限约束；不提供永久金币收入、永久伤害或时代经验。
- 有持续时间，错过不会积压为下一轮多个目标。后续可通过镜像配置试验不同固定地点，但第一版保持一个可读目标。

为了多获得一次战术选择，玩家可能花掉本应留给时代进化的经验大招。对手可以争抢，也可以逼其过度投入后保兵科技。奖励需要有限，避免「赢线 → 永久经济更多 → 永远赢线」的累积回路。

### 3.6 AI：从固定出兵节奏升级为有预算的对手

AI 通过与玩家相同的动作接口执行。先建立若干可解释策略，再让它根据公开战局转换，而不是直接随机挑选贵兵。

| 可观察局势 | AI 可选择的行为 | 可以被玩家利用的代价 |
| --- | --- | --- |
| 敌方重型比例高 | 减少继续堆盾，投入破甲和架矛 | 对大量远程或抛射的防护可能不足 |
| 敌方远程受到保护 | 先破盾、准备抛射或可执行的破阵 | 单位贵、生产慢，另一侧科技投入可能减少 |
| 敌方刚交清场大招 | 集结、短时投入进攻 | 自己若过度出兵，将暴露下一轮的大招目标 |
| 己方经验可进化 | 比较升级后剩余军费、前线撑线时间与保命大招收益 | 延后进化可能失去科技领先；立即进化可能失去前线 |
| 中立目标即将出现 | 用低成本部队争抢，或保存资源放弃 | 可被玩家诱导在小目标上花掉过多资源 |
| 英雄危险 | 撤回、保留防护或用支援接替 | 暂时损失英雄火力和施法位置 |

每次只在预算内执行动作，对未来计划保留金币/军令。对预警的响应设置明确延迟；目标失效就走正常失败判定。失败后不能补发免费技能。AI 根据已出营部队估计玩家投入，不读取未出营订单。

至少覆盖压制、科技、阵地、反重型、诱骗反击五种策略，并允许切换。评估时不能只看 AI 总胜率；需要检查它是否能应对不同构筑、是否一直选择同一研究或时代计划。

## 4. 一段预期的对局体验

1. 对方以盾卫保护两名远程，你用少量前排撑住，集结长矛与抛射支援，保留进化预算。
2. 中央补给即将出现。你发出小波，对方判断可以清场并争目标，支付经验大招。
3. 你在真实预警后支付军令开启短时防护，接受部分战损；下一组仍在营地，未被这次清场一起处理。
4. 对方大招消耗经验，升级被延后；你可以支付进化军费，但前线会暂时缺少增援。此时也可留代完整出击，争夺中央目标。
5. 对方观察到你已经升级，会反过来利用新兵尚未抵达的窗口。谁更好地保护编队、保留反制资源和抓到时机，谁获得优势。

这是希望通过原型达成的体验，尚未经过数值实测。它成立的条件是小波诱骗有真实成本，防护需要预算，升级军费不阻断核心进化，AI 不预读隐藏订单。

## 5. 后续可选扩展

先验证上述交锋，再添加两项能复用现有结构的内容：

- **时代路线二选一**：改造已有局内时代策略，而不是再新增一套科技树。每次进化在机动与阵地等两项收益间选择，完成后公开路线图标；强化行动特点，不统一加全属性。必须测「所有时代都选同一路线」是否成为必选。
- **基地设施争用插槽**：在现有三个槽位中，试验炮塔、生产设施、补给设施的取舍。生产投入减少即时城防，城防投入减少出兵效率；拆换遵守退款损耗。首版设施可作为基地功能与表现节点，单独可破坏建筑和建筑攻防是更高成本的后续工作。

多战线、飞行绕后、大量随机遗物与完整资源采集会同时改变寻路、占位、经济和 UI。它们另立玩法原型，避免与本轮公平对决一起扩充。

## 6. 实施顺序与可行性

| 阶段 | 交付范围 | 现有可复用部分 | 成本判断与主要风险 |
| --- | --- | --- | --- |
| A：形成公平基础 | 对决配置、公开观察接口、AI 预算与基本克制选择、跨时代编队测试 | 双阵营状态、`act`、30 Hz 模型、快照、规则数据 | 中；需要隔离战役参数与局外加成，排查左右更新顺序影响 |
| B：让交锋可应对 | 举盾/架矛和直射抛射规则、基础防护、技能与道具去重 | 武器弹道、攻击前摇、护盾、状态、预警与音效 | 中到高；必须保持合法弹道、身体占位、伤害结算与动画同步 |
| C：加入时机和位置 | 三格集结、原型进化军费、一个中立补给点 | 训练队列、待出营状态、人口、金币/经验、战场 HUD | 中；重点防止囤兵无限爆发和抢点持续滚雪球 |
| D：扩大构筑 | 时代策略二选一、基地设施、AI 策略切换完善 | 局内策略、研究、插槽与已有英雄 | 中到高；组合数量上升，需要分批加入与对战矩阵 |
| 独立后续 | 真人联网 | 动作接口与可序列化战局提供部分基础 | 高；需要网络与权威规则工程，另行估算 |

首个代表性切片只测两个相邻时代、已有五兵种、少量技能、一组集结规则和一个目标。通过后扩展五时代，避免同时加入所有路线导致无法定位失衡来源。

UI 延续方案 1：每代仍五张招募卡；集结/出击、基础防护使用像素图标；阶段路线复用进化操作，敌方路线与公共预警放在战场/顶部。中立目标显示在小地图和战场，不加一整排常驻任务文字。原型不需要逐个点击全军或拖拽 RTS 框选。

## 7. 用什么证明博弈成立

以下是未来实现的验收方法，不是本次已执行的测试结果。

1. **规则镜像**：同配置、同经济动作流交换左右后，比较订单、成本、冷却、战果；特别检查同时命中、移动排序和目标选择偏差。目标是消除系统性阵营优势。
2. **信息隔离**：改变玩家隐藏队列/库存、保持 AI 的公开观察不变，AI 此刻决策应不变。公开信息发生变化后，才允许经过反应延迟作出响应。
3. **动作可达**：训练完待命、拥堵出营、旧代订单、进化、防护、伤害和结算遵守两侧相同的失败/消耗规则。
4. **反制预算**：在有防护资源时，玩家和 AI 都能在规定窗口减损；无资源时承担后果。烟幕不能处理全部伤害，破甲也不能直接绕过目标规则。
5. **策略矩阵**：比较压制、科技、阵地、反重型、诱骗反击，跨多个种子、左右镜像和两个相邻时代测试。不能以单个脚本或单个种子胜率下结论。
6. **跨时代收益**：分别比较同金币与同训练时间的编队；科技领先保持价值，而预算充足、组合合理的落后一代有机会撑线或取得局部收益。
7. **经济防漏洞**：集结不越过人口/生产限制；取消退款不产生套利；损失经验不能使反复送兵成为净资源收益；目标不能积压或重复领取。
8. **真人可读性**：通过试玩观察用户能否认出举盾、架矛、危险预警、出营窗口与中立目标，并说出上一波失利可以怎样改进。只有数值胜率均衡仍不足以证明体验清楚。

最终数值以实测为准，初始目标是出现多种互有优劣的计划，而非强行把所有构筑、每个局面都调成五五开。

## 8. 设计参考

参考 Riot 官方的 [Champion Counterplay](https://www.leagueoflegends.com/en-gb/news/dev/quick-gameplay-thoughts-may-14/)：强势机制应有可理解、可执行的应对；即时战术反制与长期策略反制需要共同存在，高影响招式需要相称的反应机会，但也不能让所有技能都变得迟钝。本文据此提出适合单战线自动战斗的基础防护、预算取舍与可见预警，具体系统与数值是本项目的构思。

技术可行性依据本地现有 Godot 0.6.2 模型、技能、弹道、训练和表现模块；没有把其他作品的规则或历史设计目标作为现有实现事实。
