# 交互体验与多端UI

## 完整用户流程

首次进入：音频确认 → 简短开场 → 选砺川或铎山 → M01教程。第二次起：继续游戏/新对局/战役/试验场/档案/设置。战役地图每章三个节点，显示首通奖励与时代上限；角色和技能锁定项直接写解锁条件。

战前页面从左到右为角色、专精、技能、遗物、传承，默认显示推荐构筑，展开后可改。两个遗物槽可留空；推荐模板中的未拥有项显示获取来源，不自动装备或阻止新手开始。每次修改立即显示属性差值、实际能量费用与配置有效性；超过预算不允许开始，并指出哪条节点不合法。无需在开战前阅读所有词条。

战斗 → 时代选择/暂停 → 继续 → 胜负结算 → 明确列出击杀、进化、技能配合与奖励 → 重试/改构筑/下一关。失败建议由实际事件生成，例如“重骑造成你的主要伤害；可尝试破甲兵”，不能每局随机播放同一条提示。

## HUD布局

设计基准1280×720：顶部72px内为双方基地生命、时代、军资、学识、能量与暂停；中央约480px为可读战场；下方约140px为兵种、队列、技能和进化。侧边仅短暂显示选中实体详情。

```text
┌ 己基地HP ─ 时代 ─ 军资/学识/能量 ─ 敌基地HP ─ 暂停 ┐
│                                                      │
│ 己基地   前排—英雄—远程   ←战线→   敌部队    敌基地    │
│                                                      │
├ 4兵卡+5格队列 ─ 站位 ─ 3技能 ─ 进化/时代选择入口 ────┤
└ 一行情境提示                                          ┘
```

手机横屏改成两组拇指区：左侧4兵卡与队列，右侧3技能和进化，站位位于右组上方；顶部资源紧凑呈现，长说明通过长按暂停后的面板阅读。重要按钮目标56 CSS px，间距8px；小屏不直接把PC界面整张缩小。平台映射需实测物理触达，参考[Android至少48dp触达建议](https://developer.android.com/guide/topics/ui/accessibility/views/apps-views)与[Apple至少44pt按钮触区](https://developer.apple.com/cn/design/human-interface-guidelines/buttons)。

## 统一动作表

| 动作 | PC默认 | 手机/平板 | 反馈 |
| --- | --- | --- | --- |
| 训练四兵 | 1/2/3/4或点击 | 点兵卡 | 扣费、队列格、短确认音 |
| 专属/通用技能 | Q/W/E或点击 | 点或拖技能到战场 | 范围、目标预览、真实费用 |
| 确认施法 | 左键 | 松手在合法区域/二次点目标 | 命令提交后开始冷却 |
| 取消瞄准 | 右键或Esc | 拖回取消区/取消按钮 | 无扣费、无冷却 |
| 掩护/冲锋/撤回 | Z/X/C | 三态站位按钮 | 英雄头顶短图标与路径箭头 |
| 进化 | R或按钮 | 点进化 | 可用时强调，不自动替玩家进化 |
| 暂停/返回 | Esc | 暂停、Android返回键 | 先退出瞄准，再进入暂停 |
| 查看单位 | 点实体 | 短点实体 | 边缘详情，不挡住中心交战 |

支持PC按键重映射与键盘焦点；v1不要求手柄。按住兵卡不无限连购，长按只显示详情。队列取消必须点具体格；触屏滑动跨按钮不能触发额外购买。输入使用pointerId与commandSequence去重，多点触控允许两拇指操作，但每个指针只控制一个动作。

## 瞄准与误触处理

施法预览为半透明区域、边界与合法目标高亮；取消区固定且大于技能图标。点击模式和拖放模式都映射到同一command。资源被另一指针花掉时，在提交tick重新验证，失败保持明确提示，不能显示已施放却无效果。

屏幕外、通知中断、pointercancel、页面缩放与窗口失焦都撤销未提交瞄准。DOM控件捕获的输入不再传给战场；点击暂停不会同时发射技能。技能冷却显示环和秒数，能量不足显示缺少值，队列满与人口满用不同提示。

## 屏幕适配与生命周期

手机战斗优先横屏。原生可请求方向设置；H5方向锁定不视为保证。竖屏战前页面可用，竖屏进入战斗时暂停并提示横屏；不让画面继续跑在旋转遮罩下。平板4:3保留全战场、重排边缘HUD；超宽屏扩展背景，不扩展逻辑射程。

使用safe-area-inset避开刘海与底部手势区；Canvas与DOM共用坐标转换，点击目标在各比例下保持对应。浏览器缩放、DPR变化与原生窗口resize触发布局刷新，不改变逻辑世界尺寸。原生返回键、iOS系统边缘手势和通知出现的恢复流程见技术文档。

进入后台：立即暂停 → 保存快照 → 降低或停音。恢复：显示“继续对局”与当前军团 → 手动继续，再恢复声音。不得按真实离开时间补算金币、死亡或冷却。

## 可读性与体验设置

中文正文至少16 CSS px，关键数字18px；HUD不用装饰字体写长说明。正文使用系统中文无衬线字体，按PingFang SC、Microsoft YaHei、Noto Sans SC、sans-serif回退；标题用较重字重和军令牌材质表达主题，不把字体照片烘焙成按钮。己敌旗形、护盾形状与效果纹理支持色弱区别。提供字幕、音量分轨、关闭震动、降低动态、技能范围高对比、伤害数字开关。资源变化与警示同时有图形和短文本，声音不是唯一信息源。

设置与图鉴不在活跃战斗上长期盖住中心。菜单展开暂停并禁止战场输入；关闭后恢复之前站位与技能瞄准状态的安全默认值。
