# 十时代玩法深化：编队、进化投资与对等博弈

日期：2026-10-07。性质：下一轮设计提案，新增机制与示例数值均待原型验证。依据为 Godot 0.7.0 的十时代规则；现有成品和验收结果见 [十时代交付报告](godot-v0.7-ten-eras-report.md)。本文提出的集结、公开研发、公平对决配置与观察快照 AI 等机制尚未进入成品规则。

建议保留横向单战线、真实占位、自动交战和文明进化，把玩家的操作集中在三件事：组织哪一波军队、资源投资到哪里、什么时候交出战术资源。让每个强势行动都暴露一个对手能利用的机会。

## 当前基础与核心矛盾

当前源码包含十时代、每代五个招募槽、六位主将的时代形态、金币/战斗经验/军令、研究、炮塔、主动道具及随机事件。双方时代独立；旧兵和已付费订单保留出生时代。已有伤害类型、角色克制和前后排占位，因此新增内容应先深化这些规则。

| 检查项 | 当前行为 | 深化方向 |
| --- | --- | --- |
| 招募 | 五格训练队列，完成后有空间才出营 | 给玩家有限集结能力，控制分波和队形 |
| 克制 | 普通单位的角色克制倍率为 1.3，并有伤害类型与护甲规则 | 增加举盾、架设、冲锋条件和抛射落点，令克制能被观察与应对 |
| 进化 | 经验足够即可立即进化；基地和在场主将立即换代 | 在对等模式试验公开的进化投资阶段，形成抢升级与压线的取舍 |
| 时代强度 | 同定位下一代的攻击和生命均为上一代的五倍，价格/收入为约 1.28 倍 | 保留要求的伤害断层，重点检验进化的投入和兑现窗口 |
| 战术资源 | 进化与奇袭共用经验；英雄技能使用军令；道具有有限次数 | 提高留资源、诱骗和反制的价值，梳理功能重复 |
| AI | 有真实预算和独立经验，已能使用奇袭及烟幕；选兵仍主要依赖己方数量和随机阈值 | 根据公开敌军组成、已用技能与前线危险制定计划 |
| 随机环境 | 环境事件有预警，伤害有上限，不伤基地 | 娱乐对局保留；公平对决单独配置可预测的目标和环境 |

依据：[战斗模型](../../godot/scripts/game_model.gd)、[接敌与伤害](../../godot/scripts/epoch_combat.gd)、[技能与道具](../../godot/scripts/epoch_skills.gd)、[规则表](../../godot/assets/data/rules.json)、[时代表](../../godot/assets/data/eras.json)。

**五倍代差是本次设计最重要的约束。** 当生命与攻击都提高五倍时，低代单位击败新代单位所需的时间增加，新代单位击败低代单位所需的时间缩短；不能把这简单解释成固定的胜率或“综合强度 25 倍”。但普通的 30% 克制收益显然不足以抵消这种差距。

所以，落后方的合理目标应是提前压制升级、拖延新军团形成、保留反制资源、完成自己的进化。不能承诺同预算的旧兵靠常规克制就能硬碰新兵获胜，也不能用自动追平、暗赠经验或隐藏伤害加成制造平衡。

另一个容易遗漏的点：只说“新兵走到前线之前可以反打”不充分，因为当前在场主将和基地已经即时换代。进化投资窗口必须发生在这些换代收益兑现之前。

## 第一层：出兵顺序与编队行为

### 有限集结，让出兵形成波次

在现有训练队列旁增加“集结/直接出营”切换及一个出击图标。原型预备队上限为三名单位。

- 训练完成后进入营地预备队，继续计入人口；不能一边隐藏三十名兵一边继续生产。
- 预备队满时，队首完成订单等待，后续训练不得越过它。
- 出击按训练顺序逐个通过真实出口，检查身体空间；不会同时堆叠生成，也不会瞬移到前线。
- 旧代预备兵和已付费订单在进化后仍是旧兵。已训练完成的单位不能免费撤销返还全部投入。
- 集结的代价是前线少增援、人口被占用、生产可能受阻。

这会出现三种实际选择：立即补盾卫维持阵线；等盾卫、远程、支援组成完整小队；先发廉价一波诱出奇袭，再释放预备队。诱骗本身需要付出金币和可能的战损。

首轮不增加全军自由拖拽和复杂撤退寻路。集结与分波先解决目前最缺少的出兵时机控制。

### 行为克制，让阵容具有明确弱点

| 定位 | 拟增加的优势 | 暴露的代价 | 对方的反制 |
| --- | --- | --- | --- |
| 盾卫 | 站稳举盾时抵御正面直射，保护后方火力 | 举盾降低攻击或推进效率；防护有覆盖条件 | 抛射、破甲，或等其开始推进再压制 |
| 长兵器/反重型 | 第二排支援；架矛或架设后反制冲击目标 | 需要准备时间，移动会失去准备状态 | 远程压制、先以低成本单位接敌，迫其改变姿态 |
| 远程 | 前排保护下持续输出 | 脆弱、射程有限；直射受实体截挡 | 击破前排，或用公开落点的抛射压制后排 |
| 重型 | 早期助跑冲击；后期架设火炮或装甲平台破阵 | 占位宽、昂贵、训练慢；爆发存在准备或恢复期 | 减速、反重型、利用架设/装填空档换波 |
| 特种支援 | 有限目标的治疗、护盾、鼓舞或标记 | 自身输出低，保护它消耗队形空间 | 合法抛射、破阵，或对已暴露目标施加有限压制 |

重型单位的行为应随时代变化：战车/骑兵可依赖助跑，火炮依赖架设与装填，现代装甲依赖火力周期，未来装备可依赖蓄能与散热。统一职责和输入，避免十代都机械套用“跑够距离就冲锋”。

已有实体截挡和弹道提供基础；新增抛射需要明确曲线、飞行时间与落点，不能把普通远程攻击改成无视阵线点杀医疗兵。控制效果需要持续时间、刷新规则和上限，不能形成永久眩晕。治疗与被动盾继续遵守共享恢复预算，防止新支援组合重新造成不死前排。

## 第二层：进化成为可反击的投资

建议在独立的公平对决原型试验以下规则，保留其他模式的配置空间。

1. **投资**：支付当前进化经验，加约一至两名本时代普通兵的军费。实际军费按时代价格尺度计算。
2. **公开准备**：试验约 4–6 秒的研发阶段。双方能看见研发图标和倒计时；精确剩余金币、训练队列仍是私有信息。阶段内招募继续使用旧时代。
3. **兑现**：研发完成才更新本方时代、基地、主将、招募目录及地图；基地和主将保留生命比例。旧兵和旧订单保持出生时代。
4. **承诺成本**：首个原型不提供随时取消研发。避免反复免费启动、取消来制造假情报；基地被摧毁则直接按胜负结算。
5. **时间一致**：暂停冻结研发进度；已发射攻击和已排程奇袭保留施放时的时代参数，不能在进化瞬间免费增伤。

上述秒数和军费是测试起点，不是已验证数值。窗口太短会失去反制意义，太长或军费太高会让升级一直不值得，需要与前线旅行时间、英雄位置、时代收入一起测。

| 计划 | 想兑现的收益 | 对手可以利用的机会 |
| --- | --- | --- |
| 抢科技 | 新时代的五倍火力与后续生产优势 | 抓公开准备阶段，用现有军队压线；逼迫其先花经验奇袭救场 |
| 留代压线 | 把眼前金币投入完整编队、研究和推进 | 守住投资阶段，等新代单位形成后反推 |
| 留经验奇袭 | 用清场解决一波进攻并制造输出空档 | 分波保兵、保留防护，利用其延迟进化的成本 |

对等意味着双方执行同一套投资规则，不意味着时代进度必须相同。地图随双方最高已完成时代变化，研发开始和背景切换都不能替另一方完成进化。

十时代内容可通过跨时代长局、分段战役和指定起始时代演练体验。无需强迫每局都经历全部十代，更不能为了展示十代而自动替双方升级。

## 第三层：强招、反制与战术预算

### 基础应对必须人人可用

双方共享一种不依赖主将解锁的短时“紧急防护”，以军令和冷却为代价。防护只处理己方合法范围内的单位，按现有减伤/护盾上限结算，不能同时叠成无敌，也不能恢复已经阵亡的兵。

其作用是减少同代奇袭战损，让提前保留军令有价值；不会保证旧兵能扛住高代五倍火力。另一种应对来自集结：预备队未出营时不属于此次前线清场目标。

奇袭落点、作用范围、伤害节奏和声音预警必须对应真实结算。需要测试人能否在手机上完成识别、选区、施放；只出现红圈却无法执行有效动作，仍然缺少反制。

### 道具做有限选择，避免每局开场全部按完

先试两个携带槽、固定总充能预算，复用已有三种道具并重定义其职责。

| 道具 | 主要用途 | 反制和代价 |
| --- | --- | --- |
| 战鼓 | 把完整的一波变成短时推进 | 使用时暴露进攻窗口；对手可分波、架设或暂时防护 |
| 烟幕 | 在有限区域削弱直射，掩护编队形成 | 抛射与区域伤害仍有效；不能对所有伤害全面减免 |
| 补给箱 | 优先加快特定生产阶段，帮助补线或组织下一波 | 使用次数有限；减少同时赠金币、军令与训练的通吃收益 |

当前主动烟幕主要减速敌军，掩护效果是提案中的修改；当前补给箱同时有金币、军令和训练推进，修改需同步描述和 AI 判断。战鼓类技能与道具要有不同适用范围、持续时间或预算成本，不能只是换图标的同一个效果。

“交进攻技能”与“留防护军令”争用预算，“用补给补线”与“把补给留给新时代第一波”争用充能。强效果越集中，失误后暴露的空档越明确。

## 第四层：构筑差异与信息博弈

这层放在前三层对局成立之后加入，分开验证每项收益。

### 时代路线：选择行动风格

复用局内升级选项，在少数关键时代试验互斥路线，例如机动突击与阵地火力。路线完成后公开图标。

- 机动路线强化重新形成一波、抢时机或转入推进，付出站稳火力/防护的代价。
- 阵地路线强化架设后的射程、防护或集中火力，付出移动与重新准备的代价。
- 每项收益必须绑定条件；避免两条路线都只是攻击、生命、收入全加。
- 首个切片只做一次二选一；扩展十代时先设置少量关键节点，避免立即产生庞大的互斥分支。

### 基地插槽：城防与生产占用同一空间

现有三个炮塔槽可逐步允许放置炮塔或训练设施。生产设施减少直接城防，炮塔减少可投入生产强化的空间；出售与拆换有损耗。先把它们实现为基地功能节点，独立可破坏建筑另做原型。

设施的类别和完成状态公开，玩家能据此判断对手重视守城还是下一波。首轮不加无限叠加的永久税收设施，避免领先方既强军又获得持续经济优势。

### 侦察：花军令换有限情报

在集结规则稳定后试验一个短时侦察操作：暴露敌方已经存在的营地预备队类别或数量，代价为军令和冷却。侦察期间信息对双方遵循同一规则。

日常公开信息包括已出营军队、时代、主将、设施、完成的路线及战场预警；隐藏信息包括未出营队列、资源库存和道具余量。侦察只揭示规则允许的内容，不读取对手下一条输入或尚未作出的决定。

因此可以通过公开的小波掩盖真正的集结，也可以支付侦察成本降低误判。首轮不引入整张地图战争迷雾，避免同时重做镜头、侦察范围和寻路。

## 第五层：战线目标与随机性

一个中央定时补给点可以让“占据中线”具有战术价值，但它不能自动奖励已经领先的一方更多长期经济。

- 试验每 60–90 秒出现一次，提前约 8 秒预告；地点、时间和剩余有效期公开。
- 只有正常地面军团能捕获，召唤物不单独占点；敌军进入争夺范围时停止捕获。
- 原型奖励先用一次性约 25 军令，受军令上限约束。不送进化经验、不永久加收入、不积压未领取目标。
- 双方都可选择放弃目标保存升级预算，或投入一波争抢。若实测显示“原本赢线的人总是顺便拿点”，而放弃没有合理收益，就先取消目标，而非继续增加奖励。

经典模式继续保留陨石、坠机等弱随机奇袭与时代动态背景。公平对决建议默认关闭随机伤害事件，或另设有明确时间表的对称事件规则；仅共用随机种子不能保证公平，因为双方站位和兵种不同，同一事件也可能影响一方更多。三候选背景和天空动物可以继续作为纯表现层随机，不改变竞技碰撞与收益。

## 各时代如何体现不同的交锋

以下是玩法主题，属于架空游戏设计，不把倍率和装备搭配解释为历史模拟。

| 时代 | 可读的战术主题 | 主要应对方式 |
| --- | --- | --- |
| 石器部落 | 重型冲击、投掷、战鼓集结 | 助跑阻断、分波、保持反重型前线 |
| 青铜城邦 | 盾阵保护与战车爆发 | 破甲、抛射、抓盾阵推进时机 |
| 古典帝国 | 第二排协同与弩炮架设 | 前后排组合、装填空档、抛射压制 |
| 中世纪王国 | 骑兵冲锋与长兵器准备 | 诱出准备姿态、减速、反冲锋 |
| 火药列阵 | 齐射、装填与火炮落点 | 分波承担第一轮，利用装填期推进 |
| 工业战壕 | 架设、压制与区域炮击 | 避免全军聚集，烟幕掩护与有限防护 |
| 二战钢盔 | 装甲推进、反装甲与支援火力 | 同时代反重型组合，抓高投入编队缺口 |
| 现代机械化 | 精确打击与暴露目标 | 识别标记、保留反制、组织下一波 |
| 无人战术 | 侦察、干扰与协同输出 | 侦察预算取舍、失去支援时的输出空档 |
| 轨道文明 | 蓄能、护盾与高强度落点 | 识别蓄能，破盾、防护与分波 |

十代使用同一套招募与战术入口，特色体现在动作条件和战术周期。需要新增举盾、架设、蓄能等角色姿态时，继续用指定 Sub2 / gpt-image-2.5 生成并审查完整动作素材；本构思阶段不把尚未生成的姿态算作已实现内容。

## 对等 AI 与公平模式契约

公平对决先面向单机 AI。真人联网是独立工程，需要权威状态、同步、断线与网络输入规则，不包含在本提案首轮中。

| 维度 | 规则 |
| --- | --- |
| 起始条件 | 两侧相同初始资源、基地、人口、训练容量和可选内容预算 |
| 局外成长 | 使用统一竞技模板或等预算横向配置；战役的永久数值优势不带入 |
| 行为权限 | AI 与玩家通过相同动作入口出兵、集结、研发、道具、侦察与防护 |
| 信息权限 | AI 只收到公共观察快照和自己的私有状态；侦察信息按相同规则进入快照 |
| 响应时间 | AI 在预警公开后才开始响应，按难度经过明确反应延迟 |
| 难度 | 增强计划、观察和预算分配；不暗改伤害、收入、经验和冷却 |
| 参数隔离 | Boss 援军、关卡金币、特殊基地加成由战役配置提供，不混入公平对决 |
| 胜负与反制 | 相同消耗、目标合法性和失败规则；不以隐藏补偿强行制造五五开 |

AI 先建立压制、科技、阵地、反重型与诱骗反击几类计划，再根据公开局势转换。敌方重型增多时补反重型；敌方刚交奇袭时组织下一波；己方研发将消耗军费时评估前线是否能支撑；危险时选择救场还是承担损失留经验。

难度提升应让 AI 更会利用机会。它也应该能被小波诱骗，也会因过度投资、交早防护或错误选兵暴露弱点。

## 一段目标对局

1. 同时代，对方以盾卫保护远程。你用少量前排撑线，集结破甲与抛射支援，留一部分军令。
2. 你释放小波试探。对方选择消耗经验奇袭；你在预警后使用有限防护，接受部分战损，营地下一组未一起被清场。
3. 对方的进化被经验支出延后。你开始公开研发，支付军费，此时主将和基地仍是旧时代。
4. 对方抓这段窗口组织推进；你必须用预备队和剩余战术预算撑线，也可能因过早研发失去基地。
5. 成功撑住后，你完成进化，主将换装，新兵形成明显强势波次。对方此时的目标是拖住推进并完成自己的研发。
6. 当双方再次同代，编队与战术周期重新成为重点。胜负由之前的投资、留兵和资源支出共同累积。

这是需要验证的体验。诱骗不保证成功、防护不保证零战损、先升级也不保证必赢；每个行动都应留下一项可复盘的投入和机会成本。

## 实施切片与验收

| 顺序 | 原型范围 | 成本与关键风险 |
| --- | --- | --- |
| 第一片：公平基础 | 独立对决配置、公共观察快照、同规则 AI、左右镜像回放 | 中；防止战役参数与隐藏信息进入 AI，排查同时行动偏差 |
| 第二片：编队与应对 | 两个相邻时代、现有五槽兵种、三格集结、少量姿态、基础防护 | 中到高；占位、弹道、动作与命中必须同步，不能瞬移穿线 |
| 第三片：进化取舍 | 研发阶段、军费、暂停/存档支持，与奇袭经验预算联动 | 中；检查主将与基地收益兑现时间，避免升级成为无条件必选或长期不可选 |
| 第四片：构筑扩展 | 一次路线二选一、一个设施选择，再逐代扩展 | 中到高；逐项加入，避免多个系统同时改变后无法定位失衡 |
| 可选后续 | 侦察、一个中央补给目标、更多时代行为 | 中；必须先证明改变决策，避免只增加按钮和领先奖励 |

首个切片建议选古典帝国/中世纪，验证盾阵、第二排、抛射和冲锋；再用二战/现代机械化验证火力平台与反重型。两个切片成立后，再覆盖全部十代。UI 继续方案 1：每代五张兵卡，训练区增加集结与出击图标，进化按钮显示研发进度，路线与设施复用现有二级操作面板。

验收关注实际决策而不仅是内容数量：

1. 同配置交换左右，检查资源、生产、冷却和战果；对同时命中和同位置目标选择做专项验证。
2. 隐藏队列或资源改变、公共观察不变时，AI 的当前决策保持不变；合法侦察后再允许更新。
3. 验证同预算/同生产时间的阵容矩阵，确认同代反制有效；跨代测试关注能否合理撑线和追科技，不强行要求旧兵正面胜新兵。
4. 分别比较早研发、压线、留经验奇袭等计划；如果所有合理场景都是经验一够立即研发，投资取舍仍未成立。
5. 集结不绕过人口与队首等待；旧兵不免费升级；退款、道具、己方战损经验和补给奖励不能构成净资源套利。
6. 用真实鼠标/触屏检查预警应对窗口，验证玩家能识别出营波次、举盾、架设、装填与研发阶段。
7. 在多种种子、左右位置和构筑下检查策略矩阵。先排除系统性阵营优势，再确认存在多种有条件成立的计划，不把所有对局都调成固定五五开。
