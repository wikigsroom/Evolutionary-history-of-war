# v0.8.0 真人联机 / Real-player online battles

新增 Go + Godot Headless + PostgreSQL 原生服务端，以及 Windows/Android 客户端的联机菜单、自由真人匹配、六位数字创建/加入房间、双方构筑与准备、原局返回和唯一结果结算。

双方使用相同经济与构筑预算，各自独立进化。服务器执行战斗、保存命令结果和精确状态后才确认；客户端只提交操作和显示过滤后的战局。重连和客户端重启恢复原身份、原比赛和席位，已执行指令不重复扣费，尚未执行的旧点击不补发。裁判、网关和数据库强制终止恢复已实测。

## English

Adds a native Go gateway, headless Godot authority and PostgreSQL persistence, together with an Online menu on Windows and Android. Features include real-player matchmaking, shared six-digit room codes with leading zeros, loadout changes, both-player readiness, original-match resume and one authoritative final result.

Both players have equal resources and build access; eras evolve independently. The server commits commands and exact checkpoints before acknowledging them. Reconnects and client restarts restore the original identity, seat and match. Executed actions remain committed; unexecuted stale clicks are sealed rather than replayed. Native referee, gateway and isolated database process-crash recovery was tested.

Extract the server ZIP and run `Start-Server.ps1`. Connect both clients to `http://<server LAN IPv4>:28187`, then use matchmaking or the same six-digit code and ready up. The server includes native runtime components and PowerShell administration; no containers or VMs are used. Windows requires the Microsoft VC++ x64 runtime. Admission defaults to ten matches.

Validation covers 35 core checks, 23 network checks, 19 real-client checks using the exported Windows resource pack, 10 native fault checks, 10 standalone server start/drain/recovery checks, 7 Go control checks, 159 existing UI checks and 187 AI/capital checks. Ten concurrent local matches sustained at least 29.96 simulation ticks/s; command ACK P95 was 260ms. APKs are signed and package-inspected, but physical Android play and mobile lifecycle tests remain pending. No hosted public matchmaking endpoint is included; public deployment requires an operator-owned persistent host and HTTPS/WSS.
