# 纪元急袭 / Epoch Rush: Pixel Command — v0.7.0

十时代 Godot 原生版首次公开安装包发布，包含营寨相向修复：左侧我方朝右，右侧敌方朝左，升级时代及受损后保持正确朝向。

This first public binary release of the ten-era native Godot game includes the camp orientation fix: the allied camp faces right and the enemy camp faces left, including damage and evolution transitions.

## 游戏内容 / Game content

- **10 时代、50 兵种、6 主将和 60 套主将时代形态**；双方独立进化，保留旧兵与已付费订单。 **10 eras, 50 troops, 6 commanders and 60 commander-era forms**; independent evolution with existing troops and paid orders preserved.
- **20 战役关卡、30 候选地图、20 炮塔、10 时代奇袭**，以及主动道具、技能、天赋、遗物和战场环境事件。 **20 campaign missions, 30 candidate maps, 20 turrets and 10 era strikes**, plus active items, skills, talents, relics and battlefield events.
- 方案 1「像素指挥卡组」界面、兵线占位与接敌排队、原生打击演出、43 音效族 / 129 变体、9 音乐与结算曲。 Direction 1 pixel command cards, physical battle lines, native combat presentation, **43 SFX families / 129 variants** and **9 music/result tracks**.

## 修复与验证 / Repair and verification

修复了 A1、A2、A4、A10 的敌方营寨被重复镜像的问题；其余时代按各自素材约定处理。修复后源码及新 Windows 内嵌资源均通过 **527 / 527** 项检查，覆盖十时代、四种损伤状态、九次连续换代及炮塔朝向。

The repair resolves double-mirrored enemy camps in A1, A2, A4 and A10 while honoring each era's artwork orientation. Corrected source and the new Windows embedded resources each pass **527 / 527** checks across ten eras, four damage states, nine consecutive transitions and turret facing.

Windows ZIP 完成 CRC 与内含 EXE 哈希核对。两个 Android 包各 19 个 JSON 与导出时源码匹配，营寨字节码与已测 Windows 相同，签名及 16 KB 原生页对齐通过。Android 尚未完成实体设备安装与游玩验收；战役难度的人类调优仍在继续。

The Windows ZIP passes CRC and bundled-EXE hash checks. Both Android packages match 19 exported source JSON files and the tested Windows camp bytecode, with signatures and 16 KB native-page alignment verified. Android physical-device installation and playtesting are pending; human campaign difficulty tuning remains ongoing.

详见 [营寨修复记录与实机对比 / repair report](https://github.com/wikigsroom/Evolutionary-history-of-war/blob/v0.7.0/docs/epoch-rush/godot-base-facing-fix.md) 和 [本次验收证据 / repair evidence](https://github.com/wikigsroom/Evolutionary-history-of-war/tree/v0.7.0/docs/qa/base-facing)。安装包对应本次修复构建，不应使用历史初版成品的校验和。
