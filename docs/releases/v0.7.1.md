# 纪元急袭 / Epoch Rush — v0.7.1

更新 Windows 与 Android 的正式品牌资源，并以四首完整 Yourset 曲目替换当前原生游戏的时代配乐轮换。

Updates official branding on Windows and Android and replaces native era music selection with four full-length Yourset songs in a shared shuffled playlist.

## 本次更新 / Changes

- **双端品牌统一**：最新男性骑士应用图标为不透明背景；菜单顶栏与营地首页使用透明“纪元急袭”文字 LOGO，LOGO 仅包含游戏名。Windows EXE 图标、Android 常规/自适应/单色图标均同步。 **Unified branding:** the latest male-knight application icon has an opaque background; menu headers and the home screen use the transparent Chinese game-name wordmark. Windows EXE and Android legacy/adaptive/monochrome icons are updated.
- **四首随机 BGM**：`黑历史 Infetar A1`、`Sirirankok 修复版`、`Loth`、`Be A Single Dog Again`。每轮随机排序并各播一次，跨轮避免相邻同曲；保留完整时长，约 9 分 16 秒。 **Four shuffled songs:** each plays once per cycle, with consecutive repeats avoided across cycle boundaries; full durations total approximately 9m16s.
- **连续播放与混音**：菜单和十时代对战共用列表，进入对战、切换菜单及双方进化不会重播或切曲。曲间 2 秒等功率交叉淡化，后台及关闭音乐保留位置和队列；暂停降低配乐。胜负平局短曲、43 类 / 129 变体的打击及界面音效继续保留。 **Continuous playback and mixing:** menus and all ten eras share the playlist. Screen changes and evolution keep the current song; songs crossfade for two seconds. Backgrounding or disabling music preserves position and queue. Result stings and 43 SFX families / 129 variants remain.
- **音量整理**：四首曲目转换为 48 kHz 双声道 Ogg，实测 -19.01 至 -18.99 LUFS；原始 MP3 不变。 **Mastering:** stereo 48 kHz Ogg songs measure -19.01 to -18.99 LUFS; original MP3 files are unchanged.

应用版本 **0.7.1**；Android `versionCode` **10**，应用 ID 不变。沿用 0.7.0 的内容与存档结构，保留独立时代、十时代营寨相向、50 兵种、六位主将及 20 关战役。

Application version **0.7.1**, Android **versionCode 10**, unchanged application ID. Content/save compatibility remains at the 0.7.0 baseline, including independent evolution, inward-facing camps, 50 troops, six commanders and 20 missions.
