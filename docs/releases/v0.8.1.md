# v0.8.1 — 正式公网联机 / Public online service

本版将真人联机上线到 SIDcloud 官方服务器 **https://jyqx-server.sidcloud.cn**，Windows 与 Android 默认使用该地址。进入「联机」后点击「同意并连接」，即可自由匹配，或与朋友输入同一个六位数字，双方准备/接受后开战。

- 原局自动重连、客户端重启恢复、提交后确认和指令去重继续有效；已用导出资源客户端实测服务进程被杀后的自动恢复与游戏数据库连接中断后的继续对战。
- 修复旧匿名身份重新入队及匹配超过一分钟后被误清理的问题；完整验证长等待、真人对手到达、双方接受、共同结算。
- 服务重启时的 HTML/空代理响应按临时网络故障处理，继续自动重连，避免刷 JSON 解析错误。
- 补齐联机中文字体，首次连接前明确提示 SIDcloud 与新加坡地区；单机进度继续保存在本机。隐私政策同步于 https://jyqx.sidcloud.cn。
- 官方部署使用原生 Linux、Nginx TLS、受限 PostgreSQL、systemd 自启/重启、健康/磁盘保护、每日备份和实际隔离恢复验证。共享 1 GB 服务器目前最多 **两局 / 四人同时作战**。
- 发布 Windows EXE/ZIP、Android debug/release APK、Windows 自部署 Server ZIP、Linux 权威服务 TAR 与 SHA256SUMS。Android 版本 **0.8.1 / code 14**；Linux 包需要另行原生安装引擎和数据库。

Windows 公网客户端 22 项、协议 23 项、原生公网故障 11 项、长等待 7 项、并发 4 项与部署运维 12 项检查通过。完整 [交付报告](https://github.com/wikigsroom/Evolutionary-history-of-war/blob/main/docs/epoch-rush/godot-v0.8.1-public-online-report.md)、[QA 证据](https://github.com/wikigsroom/Evolutionary-history-of-war/blob/main/docs/qa/v0.8.1/README.md) 与 [Linux 运维](https://github.com/wikigsroom/Evolutionary-history-of-war/blob/main/services/online-gateway/deploy/linux/README.md) 已随源码更新。

Android 已验证双包内容、签名、16 KB 对齐及与 Windows 联机资源的一致性，实体设备游玩仍待验收。备份当前在同一主机，未实现异地备份、整机/磁盘故障零丢失或跨机自动切换。两局负载样本不代表大规模承载能力。

## English

Both v0.8.1 clients now default to the SIDcloud public endpoint **https://jyqx-server.sidcloud.cn**. Open Online, agree and connect, then choose real-player matchmaking or enter the same six-digit room code. Both players ready/accept before play. The public service runs natively in Singapore and admits two simultaneous matches on the shared 1 GB host.

This release fixes stale-identity and long-queue expiry, completes native Chinese font coverage, and introduces explicit first-connection and region notices. Exported Windows clients recover their original committed match after a game-gateway crash and interrupted dedicated database connections. Native systemd supervision, TLS renewal, health/disk guards, daily backups and isolated restore validation are deployed.

Artifacts include Windows EXE/portable ZIP, two Android APKs, a complete native Windows private-server ZIP, a Linux authority TAR and SHA256SUMS. Android is version 0.8.1/code 14. The Linux archive requires a separately installed native Godot runtime and PostgreSQL. Check artifact hashes after download.

Physical Android operation remains pending. On-host backups do not protect against host or disk loss, and multi-host failover is not implemented. Public two-match testing is limited capacity evidence, not a large-scale or long-term availability guarantee.
