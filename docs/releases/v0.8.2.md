# 纪元急袭 v0.8.2

进入联机页即自动连接正式服务，移除服务器地址、地址编辑与手动连接按钮。首次失败及大厅断开按 2、4、8 秒递增重试，随后每 8 秒重试；应用后台暂停，回到前台恢复。身份过期自动重新验证，原局重连继续保留席位、时代与指令序号。

重排像素联机界面：统一图标、按钮和输入框的尺寸与边框，放大角色并裁去透明留边，房间双方角色并排显示，准备与离开按钮集中排列。六位码支持数字键盘、前导零、输入提示及回车加入；不足六位时禁用提交。连接失败、处理中、匹配中和邀请已接受时，相关按钮有明确禁用状态。修复旧大厅轮询覆盖新房间状态，以及结算后误显示重连的问题。

Windows x64 与 Android arm64（版本 0.8.2 / versionCode 15）同步更新。Android 完成包结构、签名、16 KB 对齐以及与 Windows 相同的联机脚本和字体检查；实体 Android 设备试玩仍待完成。隐私网页与下载文档同步说明自动连接行为，运营者为 SIDcloud。

本次发布四个客户端包与校验文件。正式服务继续运行兼容的 0.8.1，战斗协议与模拟哈希一致；无需更新或迁移对局数据库。[完整验证记录](../qa/v0.8.2/README.md) · [详细调整报告](../epoch-rush/godot-v0.8.2-online-layout-report.md)。

## English

Opening Online automatically connects to the official service. The address field and manual connection button have been removed. Initial and lobby failures retry after 2, 4 and 8 seconds, then every 8 seconds; backgrounding pauses polling and returning resumes it. Expired identities are renewed automatically and original-match recovery retains the seat and command cursor.

The pixel lobby now uses consistent icon sizes, button frames and code-input styles. Enlarged, cropped commander portraits sit side by side in rooms, with compact ready/leave actions. Six-digit codes preserve leading zeros, use the numeric keyboard and support Enter; incomplete codes cannot be submitted. Stale polling no longer overwrites new room states, and finished matches no longer show a false reconnect state.

Windows and Android packages are updated together. Android package/signature/alignment checks pass; physical-device playtesting is pending. The policy and downloads describe the new automatic connection behavior. This is a client patch compatible with the existing 0.8.1 authority; the simulation contract is unchanged.
