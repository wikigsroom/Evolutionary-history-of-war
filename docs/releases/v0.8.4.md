# 纪元急袭 v0.8.4

本版同步更新 Windows、Android 与权威服务端，模拟契约哈希为 `c4cc669cf72e3436ead02be38f264934e399670d552197dff8dcb12de203f766`。

- 修复结算返回大厅：先解绑结算战斗视图，再清理服务端活动记录、客户端比赛状态、重连计时和旧战斗投影；进行中的对局从暂停菜单返回大厅时不会误确认结算；无比赛状态的网络事件不会再次触发重连。
- 修复生产出口与阵线：所有单位按出生/生产顺序形成前后关系，不再按远程、近战或角色标签插队；敌方营门占位体不会冻结已完成订单；己方生产线无后方空间时订单继续等待，避免单位反向插入和重叠。
- 修复接敌寻路：单位可锁定身后最近的敌方实体并转向清理卡在营门下方的敌军，移动与身体碰撞共用完整占位检查。
- 时代攻击代差缩减为原差值的 50%；时代进化经验需求统一降至原值的 30%。
- 简单与标准 AI 移除额外数值经济倍率并降低决策压力；困难 AI 保留更高的基础资源和收入系数。
- 指挥官阵亡扣除当前时代升级经验的 20%，并记录 `commanderLoss` 事件。
- 时代升级独立结算，成功升级的一方首都按新时代生命比例成长并立即回满；对手时代、首都生命和资源不被连带修改。
- 服务端发布改为清单哈希校验、真实裁判 IPC 预检、排空后原子切换与健康检查；任何预检或启动失败都会保留旧服务并自动回滚，避免再次因 Godot 编辑器导入阻塞线上服务。
- Windows 原生服务首次使用空数据目录时不再依赖可选的 `ConvertTo-SecureString` 模块，初始化凭据可在干净 PowerShell 主机上完成。

## English

v0.8.4 updates the Windows and Android clients together with the authoritative server. The simulation contract hash is `c4cc669cf72e3436ead02be38f264934e399670d552197dff8dcb12de203f766`.

- Fixed result acknowledgement and lobby return so the battle view is detached before terminal state cleanup; finished matches clear activity, reconnect timers and stale projections without affecting an active match viewed from the pause menu.
- Fixed gate occupancy and formations: soldiers keep production/birth order, enemy gate bodies no longer freeze completed orders, and a full rear lane keeps the order queued instead of reversing the line or overlapping.
- Fixed target selection and travel so a unit can turn toward the nearest enemy behind it and clear bodies trapped below a gate.
- Reduced the era attack gap to half of its former difference and reduced every evolution XP requirement to 30% of the previous value.
- Removed extra economy multipliers from Easy and Standard AI while keeping a stronger economy on Hard.
- Commander death removes 20% of the current era's evolution XP cost and emits a `commanderLoss` event.
- Era evolution is independent per side; the evolving capital scales with the new era and heals to full without changing the opponent.
- Server deployment now verifies the manifest, performs a real referee IPC preflight, drains admissions before an atomic switch, and rolls back on any health failure; a hanging editor import can no longer block a live update.
- A clean Windows server data directory creates its protected database credential without requiring the optional `ConvertTo-SecureString` module.

The full two-client native online regression passed 24/24 with no script errors. Android physical-device playtesting remains pending, and a running service must be drained before changing its simulation files.
